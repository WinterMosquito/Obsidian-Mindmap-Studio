# 🧠 MindMap Studio

> 在 Obsidian 中将 Markdown 渲染为思维导图。打开 `.mindmap.md` —— 一个普通的 Markdown 文件 —— 以思维导图编辑；Markdown 大纲可往返。基于 [simple-mind-map](https://github.com/wanglin2/mind-map) 引擎，由 [WinterMosquito](https://github.com/WinterMosquito) 开发。

## 🚀 快速上手

1. **新建**：命令面板 / 丝带点「新建思维导图」→ 先命名（默认＝前缀＋日期）→ 生成 `思维导图2026-09-06.mindmap.md` 并进入导图视图。
2. **编辑**：文件就是普通 Markdown，大纲即导图——增删改节点、拖拽排序、配置图片/链接。
3. **回写**：用「切换回 Markdown」随时切回；改动会写回文件（布局 / 视口记在插件 `data.json`）。

## ✨ 为什么用 MindMap Studio

插件是一个**渲染层**，而非格式转换器。`.mindmap.md` 是 100% 标准 Markdown —— 你的笔记、链接、反向链接、全文搜索与 Git 照常生效。插件把 Markdown 大纲解析为思维导图；你在导图中编辑后，改动会写回为 Markdown。

## 🚀 功能特性

- **纯 Markdown**：`.mindmap.md` 就是普通 Markdown（标题 + 列表），无专有格式。
- **往返保真**：未编辑的行逐字回写（frontmatter 原样保留；段落间空行与独立的 `---` 分隔线会做规范化）；标题 `#`–`######` 对应导图第 1–6 级节点，缩进列表对应更深层级。
- **Obsidian 原生双链**：`[[笔记]]` 显示为链接文本，支持悬停预览与逐级修饰键跳转（与 Obsidian 官方一致）：普通点击＝当前标签、`Ctrl`/`Command`+点击＝新标签、`Ctrl`/`Command`+`Alt`+点击＝新标签组、再按 `Shift`＝新窗口；「添加链接」联想笔记与其它文档（`.canvas` / `.base`）及非图片的库内文件（按附件处理）；图片请走「添加图片」。**指向尚不存在目标的链接**显示为**弱化配色**（同 Obsidian 阅读视图），由插件读 Obsidian 元数据缓存解析得出；悬停/点击路径不再预检，目标是否存在交 Obsidian 核心判断。新增的**文档链接**跟随 Obsidian 自身设置：开启「使用 \[\[Wikilinks\]\]」（官方默认）时写 `[[双链]]`（用专属文档图标），关闭时写 `[显示名](路径.md)`，路径形态跟随「New link format」；**附件与图片**始终写 wikilink 嵌入形态（`![[报告.pdf]]` / `[[归档.zip]]`）。**节点内显示别名**（无别名时为笔记名）；纯双链节点里编辑节点文本即等于改别名，保存后回写为 `[[笔记|新别名]]`。把仓库内文件（笔记 / 图片 / 附件，**任意类型**）拖到节点上、或在「添加链接」中选中双链：**完全空白**的节点会被写入链接显示名（成为纯双链节点）；**已有任何内容**的节点（文字、图片或原链接——纯双链节点也算）一律保留原样，链接建为**子节点**。URL **单独成节点**时仍是图标形态（无文本）。
- **节点内富文本（可点链接 + 行内语法）**：节点里的链接渲染为**可点文本**——点击即跳转，`Ctrl`/`Command`+点击在新标签打开（`+Alt` 新标签组、再 `+Shift` 新窗口）；**一行多枚链接各自可点**（不再只有第一枚生效），悬停预览分两级：**悬停到某枚链接文字上 → 预览那一枚**（一行多链接、首链为外链时尤其重要），**悬停节点其它位置 → 预览该节点承载的链接**（库内目标才有弹窗）。**URL 与其它内容混排时显示为可点地址**（不再只是图标）。行内语法按 Obsidian 阅读视图口径在节点内呈现：`**粗体**` / `__粗体__`、`*斜体*` / `_斜体_`、`` `行内代码` ``（含双反引号跨度）、`~~删除线~~`、`==高亮==`、`***粗斜***`；`\*转义\*` 消费反斜杠按字面显示；`%%注释%%` 整段隐藏（只在文件里保留；整行只有注释时按字面显示）。文件原文逐字保真；**段落（多行）节点里的链接同样可点**。**超长节点**（> 2000 字）只显示开头并以 `…` 标示（悬停有说明），完整内容仍在文件中——这同时避免了超长文本拖慢画布。双击这类节点编辑的是**文件里的那一行**（双链、URL、行内语法原样可见可改）。
- **图片**：仓库内图片联想、统一尺寸、`![[路径]]` 往返；拖动右下角手柄即可调整节点图片大小，尺寸以 Obsidian 官方嵌入语法写回笔记（`![[图.png|300]]` 仅宽等比、`|300x150` 指定宽高、`![alt|300](url)` 外链图）；清空文本后节点被图片独占——该节点已无文本，故节点搜索不会命中它。**段落（文本）节点行内的图片同样会渲染**（取首行；段落里的链接同样可点，见上条）。
- **打开即 100%** 且整图居中；需要全览时点「适应画布」，点「重置缩放」回到 100%（屏幕上可见的内容保持原位；自动整理后自动适应画布）；**六种布局**（切换布局后自动整理并适应画布）+ 连线样式可切换（**自动**＝随布局，另可选曲线/直连/折线；按文件记忆；目录组织图/时间轴/鱼骨图为固定直线，下拉显示「自动」）、节点搜索、自动整理、大图性能模式、PNG 导出；**拖拽换父辅助**——拖到节点中心附近即挂为其子节点，拖到两兄弟之间即插入其间（实时高亮落点）。
- **状态持久化**：每个文件的布局、视口与「打开方式」偏好会保存（插件 data.json），重开/改名/切换视图后保持。
- **中心节点 ⇄ 文件名**：修改中心节点会自动重命名 `.mindmap.md` 文件（Obsidian 原生更新链接/反链）。

## 📖 使用说明

### ① 新建 / 打开
- 命令面板或丝带点 **「新建思维导图」** → 先弹出命名框（默认＝前缀＋日期，重名自动加序号）→ 生成 `思维导图2026-09-06.mindmap.md` 并进入导图视图。
- 任意 `.mindmap.md` 文件：右键 → **「以思维导图打开」**（或同一命令），另有 **「以 Markdown 打开」** 返回。你选择的视图会被记住。
- 命令面板另有 **「在当前文件文件夹新建思维导图」「搜索节点」「适应画布」「自动整理思维导图」「导出为 PNG」**——与工具栏同款动作。

### ② Markdown 如何变成导图
每个 `.mindmap.md` 都是 100% 标准 Markdown——插件只负责把它渲染成导图，并把你的编辑写回：

```markdown
# 项目计划                  ← 中心节点（= 文件名）
## 目标                     ← 一级子节点（#）
- 里程碑一                  ← 子节点（列表）
- 里程碑二
###### 细则                ← 6 级标题
- 第 7 级列表项              ← 标题下的列表缩进 → 第 7 级
```

> `#`–`######` → 第 1–6 级节点 · 嵌套列表更深层级 · `[[笔记]]` / `[[笔记|别名]]` → 可点链接（节点内显示别名）· 裸 URL → 可点地址 · 行内语法直接在节点内呈现（`**粗体**` / `__粗体__`、`*斜体*` / `_斜体_`、`` `行内代码` ``、`~~删除线~~`、`==高亮==`、`***粗斜***`；`\*转义\*` 按字面显示、`%%注释%%` 隐藏——整行只有注释时按字面显示）· `![[图片]]` → 图片（`|300` 设置尺寸）· 段落与代码围栏保留为文本（**段落里的链接同样可点**）。
>
> 非图片嵌入（如 `![[报告.pdf]]`）**单独成节点**时显示为**附件图标**：点图标、或 `Ctrl`/`Command`+点击节点即可打开（PDF / 音频 / 视频），悬停节点同样触发 Obsidian 原生预览；与其它描述文字混排时按库内链接渲染为**可点文本**。都不会在节点内内嵌渲染——导图节点无法承载 Obsidian 的媒体内嵌视图。
>
> **拖入的系统文件**（图片 / PDF / 音频视频 / 笔记 / 其它任意文件）：**先选中一个节点**（未选中会提示先选择），再把文件拖入——复制进「附件默认存放路径」后挂到该节点（可嵌入的类型写成嵌入语法 `![[报告.pdf]]`，其余写成链接 `[[归档.zip]]`）；按住 **`Ctrl`（Windows/Linux）/ `Option`（macOS）** 拖入则**不复制**，改为插入指向原位置的绝对链接 `[文件名](file:///…)`（仅当路径含空格/括号时用 `<…>` 包裹；点击交系统默认应用）——与 Obsidian 的拖放行为一致。

### ③ 常用操作（导图视图内）
| 想做什么 | 怎么做 |
|---|---|
| 编辑节点文本 | 双击节点（或按 **F2**；输入框内 F2 不接管；**未选中节点时 F2 归 Obsidian＝重命名文件**）。**纯双链节点**：改的就是**别名**（保存后写回 `[[笔记\|新别名]]`）。**其它富节点**（混排链接 / URL / 轻标记 / 超长）：弹出插件弹窗**编辑「文件里的那一行」原文**——`[[双链]]`、URL、`**粗体**` 语法都看得见、改得动，弹窗内有「**节点将显示为**」实时预览；保存后逐字写回该行（引擎的原位编辑框对这类节点不可用） |
| 跳转节点里的链接 | 点节点内的链接文本（当前标签打开）；`Ctrl`/`Command`+点击（新标签打开，点节点任意处亦可，无链接时按节点原链接处理）、再按 `Alt` 为新标签组、加 `Shift` 为新窗口；悬停**那一枚**链接出 Obsidian 原生预览（未解析目标不预览） |
| 添加子节点 / 同级节点 | 右键节点 → **添加子节点 / 添加同级节点**（同级也可按 Enter） |
| 删除节点 | 右键 → **删除节点** |
| 添加链接 | 选中节点 → 工具栏/菜单 **添加链接**（选笔记或粘贴 URL）。**完全空白**的节点写入显示名；已有任何内容（文字 / 图片 / 链接）的节点保留原样、链接建为子节点；URL 单独成节点时保持图标形态 |
| 添加图片 | 选中节点 → **添加图片**（从仓库、剪贴板或文件） |
| 拖拽挂链接 | 从文件列表把**任意库内文件**拖到选中节点上——节点即挂上该链接（完全空白节点：文字变为显示名；已有任何内容：新建链接子节点）；拖图片＝设为节点图片。未选中节点时在根节点下新建链接节点（图片需先选中节点） |
| 拖入系统文件 | **先选中一个节点**再拖入（未选中会提示）：图片设为节点图片，其它文件复制进库并按类型挂载（笔记＝双链、其余＝附件；可嵌入类型写成 `![[报告.pdf]]`）。按住 **`Ctrl`（Win/Linux）/ `Option`（mac）** 拖入则**不复制**，改插入绝对链接 `[文件名](file:///…)`（路径含空格/括号时用 `<…>` 包裹） |
| 拖拽换父 | 拖到目标节点中心附近=挂为其子；拖到两兄弟之间=插入其间（落点实时高亮） |
| 调整节点图片大小 | 悬停图片，拖动右下角手柄（等比缩放） |
| 图片独占节点 | 清空节点文本：双击清空，或右键 → **移除文本** |
| 排版 | 工具栏：**自动整理**、**重置缩放（100%）**、**适应画布**、放大/缩小 |
| 查找节点 | 工具栏搜索框 |
| 拆分节点内双链 | **编辑这类节点后自动拆分**：与描述文字混排的文档/附件双链移入子节点（节点保留文字；图片与外链不动），可在设置中关闭；命令 **拆分文档内全部混排双链** 可批量处理整篇（含未编辑的存量节点），整批算一步——**一次 `Ctrl`/`Command`+`Z` 即可撤销** |
| 导出 | 工具栏 **导出 PNG** |
| 返回 Markdown | **「切换回 Markdown」**（恢复进入前模式） |

### ④ 保存与持久化
- 未编辑的行**逐字回写**（frontmatter 原样保留；段落间空行与独立的 `---` 分隔线会做规范化）；**纯双链节点**（整行只有一个双链）的编辑即**改别名**，回写为 `[[笔记|新别名]]`（清空文本 = 去掉别名，链接保留；文本与链接共存的节点仍按「文本 + 链接」回写）。
- 布局、视口与「打开方式」按文件记在插件 `data.json`；节点图片尺寸则以官方嵌入语法（`![[图|300]]`）写入笔记本体。
- 编辑**中心节点**会自动重命名 `.mindmap.md`（Obsidian 原生更新链接/反链）。
- 配置仅存本地，无遥测，插件**不发起任何网络请求**——不会有任何数据外发。
- **仅在你主动要求时**才会触及仓库之外的文件：按住 `Ctrl` / `Option` 拖入文件所生成的绝对链接（`file:///…`）在你点击时交给系统默认应用打开；插件不会读取、复制或上传这些文件。

### ⑤ 与 Obsidian 的差异（有意保留）

导图视图是**第三种视图**（既不是阅读视图、也不是编辑视图），少数交互按本视图语义定，均已登记（`AGENTS.md` K56 ⑤）：

| 项 | Obsidian | 本插件 |
|---|---|---|
| `F2` | 重命名当前文件 | 同左：**未选中节点时** F2 交给 Obsidian（重命名文件）；**选中节点时**编辑该节点（选中中心节点时同样是改文件名） |
| 重命名后自动更新链接 | 设置项「自动更新内部链接」（默认开启） | 同左：设置项「自动更新内部链接」（默认开启）；关闭后不改链接、不清理删除的引用 |
| 新增链接写成什么 | 跟随「使用 \[\[Wikilinks\]\]」「新链接格式」设置 | 同左，但**仅文档链接**：开启 Wikilinks（官方默认）时写 `[[双链]]`，关闭时写 `[显示名](路径.md)`；改写沿用你原有的路径前缀。附件与图片始终写 wikilink 嵌入形态（`![[报告.pdf]]` / `[[归档.zip]]`） |
| 输入 `[[` 联想候选 | 编辑器内行内候选 | 原文编辑弹窗是纯文本框，无行内候选 → 用「添加链接」弹窗的库内文件联想 |
| 反向链接 / 出链 / 未链接提及面板 | 核心插件 | 不重复实现——Obsidian 自带面板作用于当前文件，导图视图下同样可用 |
| 不可渲染的库内文件（zip / docx / 其它）点击 | 交系统默认应用 | 同左 |

完整的 Markdown ↔ 思维导图映射规则见 [`docs/markdown-mindmap-standard.md`](docs/markdown-mindmap-standard.md)。

## 📦 安装

- **社区插件**（上架后）：**设置 → 第三方插件** → 搜索 *MindMap Studio*。
- **从 GitHub Release 安装（推荐）**：从仓库 [Releases](https://github.com/WinterMosquito/Obsidian-Mindmap-Studio/releases) 页面下载最新版本的附件（`main.js`、`manifest.json`、`styles.css`），复制到 `<仓库>/.obsidian/plugins/mindmap-studio/`，重启 Obsidian 后在 **设置 → 第三方插件** 启用。
- **从源码构建**：`npm install && npm run build` 生成 `main.js`，与 `manifest.json`、`styles.css` 一起放入插件目录。

> 需要 Obsidian 1.13.0 或更高版本，仅支持桌面端（Windows / macOS / Linux）。配置仅存本地（插件 `data.json`），无遥测、不发起网络请求。`main.js` 由 CI 构建并随每个 GitHub Release 发布（不提交进仓库）。

```bash
npm install
```
