# 🧠 MindMap Studio

> 在 Obsidian 中将 Markdown 渲染为思维导图。在笔记的 frontmatter 写 `类型: Mindmap`（英文库写 `Type: Mindmap`），它打开时即是导图；任何笔记也可用右键**「以思维导图打开」**临时预览 —— 仍是普通的 Markdown 文件，大纲可往返。基于 [simple-mind-map](https://github.com/wanglin2/mind-map) 引擎，由 [WinterMosquito](https://github.com/WinterMosquito) 开发。

## 🚀 快速上手

1. **新建**：命令面板 / 丝带点「新建思维导图」→ 先命名（默认＝前缀＋日期）→ 生成 `思维导图2026-10-13.md`（文件头带 `类型: Mindmap`）并进入导图视图。已有笔记也随时可用。
2. **编辑**：文件就是普通 Markdown，大纲即导图——增删改节点、拖拽排序、配置图片/链接。
3. **回写**：用「切换回 Markdown」随时切回；改动会写回文件（布局 / 视口记在插件 `data.json`）。该按钮会把属性改写为 `类型: Markdown`，即**此后不再自动以导图打开**。
4. **嵌入**：在**任意笔记**里写一个语言标识为 `mindmap` 的围栏代码块，阅读视图 / 实时预览就地把块体渲染为**只读导图**——形态对齐内置 Mermaid、容器随内容、不可拖动、不写文件；块体语法与导图文件正文完全一致，无需新学一套格式。

## ✨ 为什么用 MindMap Studio

插件是一个**渲染层**，而非格式转换器。声明为导图的笔记是 100% 标准 Markdown —— 你的笔记、链接、反向链接、全文搜索与 Git 照常生效。插件把 Markdown 大纲解析为思维导图；你在导图中编辑后，改动会写回为 Markdown。

## 🚀 功能特性

- **纯 Markdown**：导图文件就是普通 Markdown（frontmatter 声明 + 标题 + 列表），无专有格式、无专用扩展名。
- **往返保真**：未编辑的行逐字回写（frontmatter 原样保留；段落间空行与独立的 `---` 分隔线会做规范化）；标题 `#`–`######` 对应导图第 1–6 级节点，缩进列表对应更深层级。
- **Obsidian 原生双链**：`[[笔记]]` 显示为链接文本，支持悬停预览与逐级修饰键跳转（与 Obsidian 官方一致）。
  - **修饰键跳转**：普通点击＝当前标签、`Ctrl`/`Command`+点击＝新标签、`Ctrl`/`Command`+`Alt`+点击＝新标签组、再按 `Shift`＝新窗口
  - **添加链接的可选面**：联想笔记与其它文档（`.canvas` / `.base`）及非图片的库内文件（按附件处理）；图片请走「添加图片」
  - **指向尚不存在目标的链接**显示为**弱化配色**（同 Obsidian 阅读视图），由插件读 Obsidian 元数据缓存解析得出；悬停/点击路径不再预检，目标是否存在交 Obsidian 核心判断
  - **新增的文档链接与图片**跟随 Obsidian 自身设置（官方「使用 \[\[Wikilinks\]\]」**同时管 links 与 images**）：开启（官方默认）时写 `[[双链]]` / `![[图片]]`（文档双链渲染为可点链接文本，无引擎图标），关闭时写 `[显示名](路径.md)` / `![alt](路径.png)`，文档路径形态跟随「New link format」；**附件**（PDF / 音视频 / 压缩包等非文档非图片）**始终**写 wikilink 嵌入形态（`![[报告.pdf]]` / `[[归档.zip]]`）。**既有**引用的形态按原文保真、不被该设置改写（拖入的三条路径——选中拖入、未选中拖入、文件夹拖入——**均**按此执行，2026-10-15 收口）
  - **节点内显示别名**（无别名时为笔记名）；纯双链节点里编辑节点文本即等于改别名，保存后回写为 `[[笔记|新别名]]`
  - **把库内文件拖到节点上**（笔记 / 图片 / 附件，**任意类型**），或在「添加链接」中选中双链：**完全空白**的节点会被写入链接显示名（成为纯双链节点）；**已有任何内容**的节点（文字、图片或原链接——纯双链节点也算）一律保留原样，链接建为**子节点**。URL **单独成节点**时显示为**可点地址文本**（无节点文本，文件里仍写作 `<网址>`）
- **节点内富文本（可点链接 + 行内语法）**：节点里的链接渲染为**可点文本**——点击即跳转，`Ctrl`/`Command`+点击在新标签打开（`+Alt` 新标签组、再 `+Shift` 新窗口）；**一行多枚链接各自可点**（不再只有第一枚生效）。
  - **悬停预览分两级**：悬停到**某枚链接文字上** → 预览那一枚（一行多链接、首链为外链时尤其重要）；悬停**节点其它位置** → 预览该节点承载的链接（库内目标才有弹窗）
  - **URL 与其它内容混排时显示为可点地址**（不再只是图标）
  - **行内语法**按 Obsidian 阅读视图口径在节点内呈现：`**粗体**` / `__粗体__`、`*斜体*` / `_斜体_`、`` `行内代码` ``（含双反引号跨度）、`~~删除线~~`、`==高亮==`、`***粗斜***`；行内数学 `$…$` 经 MathJax 渲染，**单行** `$$…$$` 渲染为块级（居中）公式（加载完成前按字面显示；**跨行**书写的块级数学保持字面）；`\*转义\*` / `\$` 消费反斜杠按字面显示；`%%注释%%` 整段隐藏（只在文件里保留；整行只有注释时按字面显示）；**GFM 管道表**（表头行 + 分隔行）渲染为真表格——单元格在内容盒内折行、表格不溢出节点（代码围栏与块级数学内的表格保持字面）
  - 文件原文逐字保真；**段落（多行）节点里的链接同样可点**
  - **超长节点**（> 2000 字）只显示开头并以 `…` 标示（悬停有说明），完整内容仍在文件中——这同时避免了超长文本拖慢画布。双击这类节点编辑的是**文件里的那一行**（双链、URL、行内语法原样可见可改）
- **图片**：仓库内图片联想、统一尺寸、`![[路径]]` 往返；拖动右下角手柄即可调整节点图片大小，尺寸以 Obsidian 官方嵌入语法写回笔记（`![[图.png|300]]` 仅宽等比、`|300x150` 指定宽高、`![alt|300](url)` 外链图）；清空文本后节点被图片独占——该节点已无文本，故节点搜索不会命中它。**段落（文本）节点行内的图片同样会渲染**（取首行；段落里的链接同样可点，见上条）。**未选中节点**时粘贴 / 拖入的图片不再提示「请先选择节点」，而是各自在中心节点下新建一个图片节点。
- **笔记内嵌只读导图**：在任意笔记里写语言标识为 `mindmap` 的围栏代码块，即就地渲染为只读导图（块体与导图文件正文**同一份大纲语法**）——**形态对齐 Obsidian 内置的 Mermaid**：容器随内容（按笔记宽度等比缩放，**只缩不放**）、内容完整可见、**不可拖动 / 缩放 / 调大小**、滚轮照常滚动笔记；只读预览**不回写文件、不写插件状态**；节点内链接仍可点、块内代码块可复制；节点数超过 500 时降级为**只读大纲**并在块内提示（详见 [② 的嵌入小节](#在笔记里嵌入只读导图)）。
- **打开即 100%** 且整图居中；需要全览时点「适应画布」，点「重置缩放」回到 100%（屏幕上可见的内容保持原位；自动整理后自动适应画布）；**六种布局**（切换布局后自动整理并适应画布）+ 连线样式可切换（**自动**＝随布局，另可选曲线/直连/折线；按文件记忆；目录组织图/时间轴/鱼骨图为固定直线，下拉显示「自动」）、节点搜索、自动整理、**大图自动进入性能模式**（节点数 ≥ 500 时只绘制视野内的节点——无设置项）、**文本节点快速渲染**（所有含文字节点由插件渲染，打开大图快数倍；双击改为内联编辑）、图片导出（PNG / SVG，按设置「导出格式」）；**拖拽换父**——把节点拖到目标节点上即挂为其子节点，拖到两兄弟之间即插入其间（引擎原生落点判定）。
- **剪贴板与节点顺序**：`Ctrl`/`Cmd`+`C` / `X` / `V` 复制 / 剪切 / 粘贴子树——以**纯 Markdown 大纲文本写入系统剪贴板**（缩进表层级、标题降为 `-` 项、有序项保留 `1.`），可在导图与任意编辑器间搬运。节点右键另含**「上移节点」/「下移节点」**——与相邻兄弟交换，首/末位有提示（一步 `Ctrl`/`Cmd`+`Z` 可撤销）。
- **状态持久化**：每个文件的布局与视口会保存（插件 data.json），重开/改名/切换视图后保持。「是不是导图」由**文件自己的属性**决定，不存在第二份状态。
- **状态栏节点计数**：导图视图激活时状态栏显示「N 个节点」（随编辑节流刷新），切走或关闭视图即清空。
- **中心节点 ⇄ 文件名**：修改中心节点会自动重命名该文件（Obsidian 原生更新链接/反链）；仅对**声明为导图**的文件生效。

## 📖 使用说明

### ① 新建 / 打开
- 命令面板或丝带点 **「新建思维导图」** → 先弹出命名框（默认＝前缀＋日期，重名自动加序号）→ 生成 `思维导图2026-10-13.md` 并进入导图视图。文件夹由**「新建导图的默认位置」**设置决定——默认跟随 Obsidian 的「新建笔记的默认位置」；也可**右键任意文件夹 →「新建思维导图」**，直接建进该文件夹。
- **让任意笔记成为导图**：在 frontmatter 加 `类型: Mindmap`（英文库 `Type: Mindmap`）——**中文键与英文键都认**，值大小写不敏感，改完双击即进导图视图；把它改回 `Markdown`（或删掉该属性）就不再自动进导图。**不必改名、不必新建、不必转换格式**。
- **任意笔记秒变导图**：任意 `.md` 文件右键 → **「以思维导图打开」**（或同一命令），可编辑并回写；**首次打开会把 `类型: Mindmap`（英文库 `Type: Mindmap`）写入文件头**，之后该笔记即正式成为导图、双击自动进导图视图（已声明则不再改动文件）。声明为导图的文件右键项则显示 **「以 Markdown 打开」**（= 把属性改写为 `Markdown`，持久降级）。
- 命令面板另有 **「在当前文件文件夹新建思维导图」「搜索节点」「适应画布」「自动整理思维导图」「导出图片」**——与工具栏同款动作。

### ② Markdown 如何变成导图
导图文件是 100% 标准 Markdown——插件只负责把它渲染成导图，并把你的编辑写回。**中心节点 = 文件名**（虚拟文档根，**不对应文件里的任何一行**）；`#` 标题从**第 1 级**节点开始：

```markdown
---
类型: Mindmap               ← 声明（英文库写 Type: Mindmap）
---
# 项目计划                  ← 一级节点（#）
## 目标                     ← 二级节点（##）
- 里程碑一                  ← 子节点（列表）
- 里程碑二
###### 细则                ← 六级节点（######）
- 第 7 级列表项              ← 标题下的列表缩进 → 第 7 级
```

> `#`–`######` → 第 1–6 级节点 · 嵌套列表更深层级 · `[[笔记]]` / `[[笔记|别名]]` → 可点链接（节点内显示别名）· 裸 URL → 可点地址 · 行内语法直接在节点内呈现（`**粗体**` / `__粗体__`、`*斜体*` / `_斜体_`、`` `行内代码` ``、`~~删除线~~`、`==高亮==`、`***粗斜***`；`$…$` 行内数学与单行 `$$…$$` 块级公式经 MathJax 渲染；`\*转义\*` / `\$` 按字面显示、`%%注释%%` 隐藏——整行只有注释时按字面显示；GFM 管道表渲染为真表格）· `![[图片]]` → 图片（`|300` 设置尺寸）· 段落与代码围栏保留为文本（**段落里的链接同样可点**）。
>
> 非图片嵌入（如 `![[报告.pdf]]`）渲染为**可点文本**（文件名）——单独成节点、或与其它描述文字混排时都一样：点文字即可打开（PDF / 音频 / 视频），`Ctrl`/`Command`+点击在新标签打开，悬停同样触发 Obsidian 原生预览。都不会在节点内内嵌渲染——导图节点无法承载 Obsidian 的媒体内嵌视图。
>
> **拖入的系统文件**（图片 / PDF / 音频视频 / 笔记 / 其它任意文件）：**图片**有没有选中节点都能拖入——选中时设为该节点图片，未选中时每张各在中心节点下新建一个图片节点；**其它文件需先选中一个节点**（未选中会提示先选择），拖入后复制进「附件默认存放路径」并挂到该节点（可嵌入的类型写成嵌入语法 `![[报告.pdf]]`，其余写成链接 `[[归档.zip]]`）；按住 **`Ctrl`（Windows/Linux）/ `Option`（macOS）** 拖入则**不复制**，改为插入指向原位置的绝对链接 `[文件名](file:///…)`（仅当路径含空格/括号时用 `<…>` 包裹；点击交系统默认应用）——与 Obsidian 的拖放行为一致。

#### 在笔记里嵌入只读导图

同一份大纲也可以**嵌在笔记里**：写一个语言标识为 `mindmap` 的围栏代码块，阅读视图 / 实时预览就地把块体渲染为**只读导图**。

````md
```mindmap
# 项目计划
## 目标
- 里程碑一
- 里程碑二
```
````

- **同一份语法**：块体与导图文件正文完全一致（标题 + 列表，同一个解析器），不存在第二套格式，也不新增设置项
- **形态对齐内置 Mermaid**：容器**高度随内容**——按笔记宽度等比缩放（**只缩不放**），内容完整可见、小图不留空白框；**不可拖动、不可缩放、不可调节大小**；**滚轮照常滚动笔记**（指针悬在图上时也一样）
- **只读且无副作用**：不回写文件、不写插件 `data.json`；节点内链接**仍可点**（由 Obsidian 自身处理，不会双开），块内代码块的复制按钮可用
- **降级一律可见**：块内节点数超过 **500** 时改为只读缩进大纲并在块内提示；空块体 / 渲染异常同样各有一行提示，不静默
- 语言键沿用 0.0.1 的 `mindmap`，**存量旧笔记无需改动即重新可用**；与抢注同一语言键的第三方插件谁生效，官方未文档化

### ③ 常用操作（导图视图内）
| 想做什么 | 怎么做 |
|---|---|
| 编辑节点文本 | 双击节点（或按 **F2**；输入框内 F2 不接管；**未选中节点时 F2 归 Obsidian＝重命名文件**）打开**内联编辑器**：所有含文字的节点都由插件渲染（**文本节点快速渲染**常开、无开关），编辑的是**「文件里的那一行」原文**——`[[双链]]`、URL、`**粗体**` 语法都看得见、改得动；`Enter` 提交、`Shift+Enter` 换行、`Esc` 停止并保留（点编辑器外或滚动画布同样提交），保存后逐字写回该行。**右键 →「在弹窗中编辑」是第二个入口**：多行弹窗（`Ctrl`/`Cmd`+`Enter` 确认、`Esc` 取消）带「**节点将显示为**」实时预览；**纯双链节点**在弹窗里改的就是**别名**（保存写回 `[[笔记\|新别名]]`） |
| 跳转节点里的链接 | 点节点内的链接文本（当前标签打开）；`Ctrl`/`Command`+点击（新标签打开，点节点任意处亦可，无链接时按节点原链接处理）、再按 `Alt` 为新标签组、加 `Shift` 为新窗口；**中键点击**链接同样直接在新标签打开；悬停**那一枚**链接出 Obsidian 原生预览（未解析目标不预览） |
| 添加子节点 / 同级节点 | 右键节点 → **添加子节点 / 添加同级节点**（同级也可按 Enter） |
| 删除节点 | 右键 → **删除节点** |
| 添加链接 | 选中节点 → 工具栏/菜单 **添加链接**（选笔记或粘贴 URL）。**完全空白**的节点写入显示名；已有任何内容（文字 / 图片 / 链接）的节点保留原样、链接建为子节点；URL 单独成节点时保持图标形态 |
| 添加图片 | 选中节点 → **添加图片**（从仓库、剪贴板或文件） |
| 粘贴图片 | 画布内 `Ctrl`/`Cmd`+`V`：**选中节点**时设为该节点图片；**未选中**时在中心节点下新建一个图片节点 |
| 复制 / 剪切 / 粘贴节点 | 选中节点时 `Ctrl`/`Cmd`+`C` / `X` / `V`：子树以**纯 Markdown 大纲**写入**系统剪贴板**（缩进表层级、标题降为 `-` 项、有序项保留 `1.`）——可粘进任意编辑器，也可把任意大纲粘回为选中节点的子节点；中心节点不会被剪切（静默 no-op）。**未选中**时 `Ctrl`/`Cmd`+`V` 把大纲粘为根节点下的新节点（剪贴板里是图片时仍优先走图片路径——见上一行） |
| 拖拽挂链接 | 从文件列表把**任意库内文件**拖到选中节点上——节点即挂上该链接（完全空白节点：文字变为显示名；已有任何内容：新建链接子节点）；拖图片＝设为节点图片。未选中节点时每个文件各在根节点下新建一个节点——**图片同样如此**（拖入的图片各自成为一个图片节点） |
| 拖入系统文件 | **图片**有没有选中节点都能拖入：选中时设为该节点图片，未选中时每张各在中心节点下新建一个图片节点。**其它文件**需先选中节点（未选中会提示）——复制进库后按类型挂载（笔记＝双链、其余＝附件；可嵌入类型写成 `![[报告.pdf]]`）。按住 **`Ctrl`（Win/Linux）/ `Option`（mac）** 拖入则**不复制**，改插入绝对链接 `[文件名](file:///…)`（路径含空格/括号时用 `<…>` 包裹） |
| 拖拽换父 | 把节点拖到目标节点上（指针落在节点内）＝挂为其子节点；拖到两兄弟之间＝插入其间（引擎原生落点判定） |
| 上移 / 下移节点 | 右键节点 → **「上移节点」/「下移节点」**——与相邻兄弟交换、走正常自动保存（一步 `Ctrl`/`Cmd`+`Z` 可撤销）；中心节点与首/末位会给出提示而非移动 |
| 调整节点图片大小 | 悬停图片，拖动右下角手柄（等比缩放） |
| 调整节点宽度 | 拖动**文字节点**的左右边框（指针变双箭头）改宽，松手后节点高度随新宽度重算；空节点与图片节点没有此手柄 |
| 全屏查看图片 | **点击节点图片**（或右键 → **全屏查看图片**）铺满窗口查看：点击任意处 / `Esc` 关闭，滚轮缩放 |
| 复制节点内代码块 | 悬停块级代码块 → 点**「复制代码」**（短暂显示 ✓；围栏信息行不计入） |
| 图片独占节点 | 清空节点文本：双击清空，或右键 → **移除文本** |
| 在空白处操作 | 空白**双击**＝在中心节点下新建节点并立即编辑（同官方 Canvas 的「双击空白建卡片」）；空白**右键**＝新建节点 / 粘贴节点 / 重置缩放 / 适应画布 / 自动整理 / 撤销 / 重做 |
| 排版 | 工具栏：**自动整理**、**重置缩放（100%）**、**适应画布**、放大/缩小 |
| 查找节点 | 工具栏搜索框（`Ctrl`/`Cmd`+`F`）：输入即搜（防抖 180ms），右侧显示 `当前/命中数` 计数；`Enter` 下一个、`Shift+Enter` 上一个、`Esc` 关闭；无命中显示「没有匹配的节点」 |
| 拆分节点内双链 | 设置 **「自动拆分混排双链」默认关闭**，开启后：**编辑这类节点后自动拆分**——与描述文字混排的文档/附件双链移入子节点（节点保留文字；图片与外链不动）；命令 **拆分文档内全部混排双链** 可批量处理整篇（含未编辑的存量节点），整批算一步——**一次 `Ctrl`/`Command`+`Z` 即可撤销** |
| 导出 | 工具栏 **导出图片**（PNG / SVG，按设置「导出格式」） |
| 返回 Markdown | **「切换回 Markdown」**（恢复进入前模式；声明为导图的文件会同时把属性改写为 `Markdown`） |

**导图视图内的快捷键**

| 按键 | 作用 | 何时**不**接管 |
|---|---|---|
| `Ctrl`/`Cmd`+`F` | 打开搜索框 | — |
| `Ctrl`/`Cmd`+`Z` | 撤销 | — |

| `Ctrl`/`Cmd`+`V` | 粘贴为选中节点的子节点——未选中时挂在中心节点下（剪贴板为图片时仍新建图片节点，见「常用操作」表） | 在输入框内 |

撤销/重做走引擎自带的历史。超大导图可撤销的步数会变少——历史按固定内存预算封顶，而非固定步数。

### ④ 保存与持久化
- 未编辑的行**逐字回写**（frontmatter 原样保留；段落间空行与独立的 `---` 分隔线会做规范化）；**纯双链节点**（整行只有一个双链）的编辑即**改别名**，回写为 `[[笔记|新别名]]`（清空文本 = 去掉别名，链接保留；文本与链接共存的节点仍按「文本 + 链接」回写）。
- 布局与视口按文件记在插件 `data.json`；**「是不是导图」由文件自己的属性（`类型` / `Type`）承载**，不存在第二份状态；节点图片尺寸则以官方嵌入语法（`![[图|300]]`）写入笔记本体。
- 编辑**中心节点**会自动重命名文件（Obsidian 原生更新链接/反链）；仅对**声明为导图**的文件生效。
- 同一份导图只保留**一个**导图编辑实例（Obsidian 本身允许同一文件开任意多个标签）：在第二个标签页再打开会提示并让位，避免两份实例互相覆盖保存。该文件的阅读视图仍可与导图并存。
- 文件被 **Obsidian 之外**改动（同步盘、其它窗口）时，该轮自动保存会**跳过并提示一次**（不覆盖他处改动）；连续写盘失败达阈值会挂起自动保存并提示，手动保存不受影响。
- 配置仅存本地，无遥测，插件**不发起任何网络请求**——不会有任何数据外发。
- **仅在你主动要求时**才会触及仓库之外的文件：按住 `Ctrl` / `Option` 拖入文件所生成的绝对链接（`file:///…`）在你点击时交给系统默认应用打开；插件不会读取、复制或上传这些文件。

### ⑤ 与 Obsidian 的差异（有意保留）

导图视图是**第三种视图**（既不是阅读视图、也不是编辑视图），少数交互按本视图语义定，均已登记（`AGENTS.md` K56 ⑤；第二标签页与侧键两行另见 K102 / K111）：

| 项 | Obsidian | 本插件 |
|---|---|---|
| `F2` | 重命名当前文件 | 同左：**未选中节点时** F2 交给 Obsidian（重命名文件）；**选中节点时**编辑该节点（选中中心节点时同样是改文件名） |
| 重命名后自动更新链接 | 设置项「自动更新内部链接」（默认开启） | **跟随官方设置**（本插件不另设开关）：关闭后不改写链接（引用变未解析）、删除也不清理引用；官方在该设置关闭后本就会在重命名时问你是否更新，故本插件不再重复提示（只在控制台留痕） |
| 新增链接写成什么 | 跟随「使用 \[\[Wikilinks\]\]」「新链接格式」设置 | 同左，但**仅文档链接与图片**（官方该设置同时管 links 与 images）：开启 Wikilinks（官方默认）时写 `[[双链]]` / `![[图片]]`，关闭时写 `[显示名](路径.md)` / `![alt](路径.png)`；改写沿用你原有的路径前缀。**附件**始终写 wikilink 嵌入形态（`![[报告.pdf]]` / `[[归档.zip]]`） |
| 输入 `[[` 联想候选 | 编辑器内行内候选 | 原文编辑弹窗是纯文本框，无行内候选 → 用「添加链接」弹窗的库内文件联想 |
| 反向链接 / 出链 / 未链接提及面板 | 核心插件 | 不重复实现——Obsidian 自带面板作用于当前文件，导图视图下同样可用 |
| 不可渲染的库内文件（zip / docx / 其它）点击 | 交系统默认应用 | 同左 |
| 同一文件开在第二个标签页 | 允许——「想开多少标签都行」；`Ctrl`+点击已打开文件的链接会开新标签 | 提示并把视图让回既有标签页：同一导图只保留一个导图编辑实例（两个实例＝两套引擎 + 两条保存管线，交错写会丢编辑）。该文件的阅读视图仍可与导图并存 |
| 鼠标侧键后退 / 前进 | 按导航历史回退 / 前进 | 同左：导图视图下侧键同样走 Obsidian 导航历史；**视图切换不是导航点**——后退直达上一个导航点（通常是上一文件），回本文件的 Markdown 视图请用工具栏/命令面板的**「切换回 Markdown」**（或文件右键「以 Markdown 打开」） |

完整的 Markdown ↔ 思维导图映射规则见 [`docs/markdown-mindmap-standard.md`](docs/markdown-mindmap-standard.md)。

## ⚙️ 设置

全部在 **设置 → MindMap Studio**（配置仅存本地插件 `data.json`；下表**按面板顺序**）：

| 设置项 | 默认 | 说明 |
|---|---|---|
| 语言 | 中文 | 界面语言——切换语言会同时改写全库导图属性键（`类型` ⇄ `Type`） |
| 默认布局 | 逻辑结构图 | 新建思维导图时使用（六种布局：逻辑结构图 / 思维导图 / 组织结构图 / 目录组织图 / 时间轴 / 鱼骨图） |
| 默认连线样式 | 自动 | 新建思维导图时使用（自动＝随布局；仅逻辑结构图 / 思维导图 / 组织结构图支持三态切换） |
| 默认主题 | 默认 | 新建思维导图时使用：默认（跟随 Obsidian 配色）/ 强制亮色 / 强制暗色 |
| 新建导图的默认位置 | 跟随 Obsidian 设置 | **「新建思维导图」**把文件放进哪个文件夹：跟随官方「新建笔记的默认位置」／仓库的根目录／当前文件所在的文件夹／下一行指定的文件夹 |
| 目标文件夹 | （空） | 仅「指定的文件夹」一档使用（**仅该档在面板上可见**）；无法解析时静默回落到仓库根目录（不会自动创建文件夹） |
| 自动保存 | 开 | 编辑时自动写回笔记 |
| 自动拆分混排双链 | 关 | 开启后，被编辑的节点含「双链 + 描述文字」时，文档/附件双链移入子节点（图片与外链不动）——会改写文件结构，故默认只在你显式开启后发生；整篇处理请用命令「拆分文档内全部混排双链」 |
| 启用节点拖拽 | 开 | 拖拽节点改变层级与顺序 |
| 导出图片倍率 | 2 | 导出 PNG 的分辨率倍率（滑杆 1–4；SVG 为矢量，不受倍率影响） |
| 导出格式 | PNG | 「导出图片」使用的格式：PNG 位图 / SVG 矢量（SVG 为矢量，故上方倍率对其无效） |

> **以下两项已收成内部常开（不再有设置项）**：性能模式（节点数 ≥ 500 时只绘制视野内节点）与文本节点快速渲染（含文字节点全部由插件渲染，双击走内联编辑）——行为即原先的「最佳默认」，此前的开关选择会被忽略。引用更新（重命名 / 删除）同样不再有独立开关，**跟随官方「自动更新内部链接」**（默认开启）。

## 📦 安装

- **社区插件**：**设置 → 第三方插件** → 搜索 *MindMap Studio*。
- **从 GitHub Release 安装（推荐）**：从仓库 [Releases](https://github.com/WinterMosquito/Obsidian-Mindmap-Studio/releases) 页面下载最新版本的附件（`main.js`、`manifest.json`、`styles.css`），复制到 `<仓库>/.obsidian/plugins/mindmap-studio/`，重启 Obsidian 后在 **设置 → 第三方插件** 启用。（每个 Release 同时附带 `LICENSE` 与 `THIRD-PARTY-NOTICES.md` 以履行许可声明——无需复制进插件目录。）
- **从源码构建**：`npm install && npm run build` 生成 `main.js`，与 `manifest.json`、`styles.css` 一起放入插件目录。

> 每个版本的变更说明见仓库 [Releases](https://github.com/WinterMosquito/Obsidian-Mindmap-Studio/releases) 页面（正文取自 [`docs/release-notes-<版本>.md`](docs/)）。

> 需要 Obsidian 1.13.0 或更高版本，仅支持桌面端（Windows / macOS / Linux）。配置仅存本地（插件 `data.json`），无遥测、不发起网络请求。`main.js` 由 CI 构建并随每个 GitHub Release 发布（不提交进仓库）。
