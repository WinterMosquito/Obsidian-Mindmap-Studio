## 2 · 权威边界（先确认听谁的，再下结论）

| 信息类型 | 唯一源 | 其他位置怎么处理 |
|---|---|---|
| 规则结论 / 硬规则 / 决策表 | `AGENTS.md` | `conventions.md` 只存**理由与历史**，冲突以 `AGENTS.md` 为准 |
| 可漂移数字（规模 / 体积 / 性能 / 测试数） | `baseline-metrics.md` | 别处引用而不复制；引用前跑该行的复核命令 |
| 豁免表行数**终值** | `AGENTS.md`「文件规模与豁免」表 | `line-count-log.md` 只是批次流水（历史读数），冲突以终值表为准 |
| 行为 / 流程 / 证据交付 | 本机测试库 `00-开发支撑/Agent提示词.md` | 不进本仓库（公开仓库不写本机路径） |
| 实机验收读数 | 本机测试库 `10-wiki/事实快照.md` | 是**快照**；与实测冲突时以实测为准，回写并记 `log` |

## 3 · `conventions.md` 的找法（**别按号段猜主题**）

编号 `[K n]` 按分配顺序递增，但条目**被归入主题组**——新条目追加到「所属组」末尾、编号继续往大走，所以**同一组的编号不连续**，`K15` 可能同时出现在两个组里（引用的是不同条目）。

- 分组清单（5 行）**在该文件开头**，本文件不复制。
- 路径：读文件开头的组表 → 锁定组 → 在该组区间内 `grep "^- \[K"`。
- 条目总数会漂移，不写死：`grep -o "^- \[K[0-9]*\]" docs/agents/conventions.md | wc -l`。

## 4 · 常见误读（已踩过的）

- `architecture.md` 的行数表**不是**「谁该拆」的判据——拆不拆只看「收口点会不会被摊开」，与该文《文件规模与豁免》开头一致。
- `baseline-metrics.md` 的毫秒与体积是**某日实测**，跨日不可直接比；只比同轮相对值（该文 §2「读数解释」）。
- `testing.md` 里 `verify:visual` 的探针描述含历史加固记录，别据此推断当前实现仍有那些缺陷。
- 行数一律按 `countSourceLines`（`\n` 切分、末尾换行不计行）；`wc -l` 会少算，两者不一致是口径差不是漂移。
