> 这里只补五件简表没写的事：**规模**（要不要通读）、**权威边界**（冲突听谁的）、
> **文档义务**（改什么要同步哪份）、**`conventions.md` 的主题导航**、

## 1 · 规模：决定「通读」还是「定点查」

| 文件 | 规模（量级） | 建议读法 |
|---|---|---|
| `index.md` | 文件清单与规模表 | 先搜文件名，只读对应记录；不是启动时必读全文 |
| `decisions.md` | ≈90 KB | 按场景/模块/K 编号只读相关决策行 |
| `architecture.md` | < 100 行 | 按模块阅读职责与依赖说明；逐文件清单见 `index.md`（豁免表已收归 `index.md`，本文件不再复制） |
| `conventions.md` | ≈1100 行（~50 KB） | 按主题或 K 编号读分层摘要与关键边界 |
| `line-count-log.md` | ≈600 行 | 平时不读；追新批次记录或行数对账时只看首尾（新记录**追加到该文件**，不进 AGENTS.md） |
| `baseline-metrics.md` | ≈470 行 | 只读你要用来判回归的那一行；其余是历史读数 |
| `testing.md` | ≈200 行 | 改测试/CI 前读一遍；`verify:visual` 那段含历史加固，读「断言什么」即可；有 DOM 副作用的模块看「fake DOM 手法」小节 |
| `process.md` | < 100 行 | 发版前整读（短） |
| `../plugin-content-rendering.md` | < 100 行 | 修改插件桥或接入处理器时查接口与生命周期 |

规模只写到**量级**（一个数量级内不重排本表）：精确值用 `wc -l docs/agents/*.md` 现算，
口径差异见 §5 最后一条。

## 2 · 权威边界（先确认听谁的，再下结论）

| 信息类型 | 唯一源 | 其他位置怎么处理 |
|---|---|---|
| 固定开发规则 | `AGENTS.md` | 固定入口，规则变化才维护 |
| 具体实现决策 | `decisions.md` | `conventions.md` 给摘要和边界；当前实现以决策表为准，仍须遵守入口硬规则 |
| 可漂移数字（规模 / 体积 / 性能 / 测试数） | `baseline-metrics.md` | 别处引用而不复制；引用前跑该行的复核命令 |
| 豁免表行数**终值** | `index.md`「文件规模与豁免」表 | `line-count-log.md` 只是批次流水（历史读数），冲突以终值表为准 |
| 行为 / 流程 / 证据交付 | 本机测试库 `00-开发支撑/Agent提示词.md` | 不进本仓库（公开仓库不写本机路径） |
| 实机验收读数 | 本机测试库 `10-wiki/事实快照.md` | 是**快照**；与实测冲突时以实测为准，回写并记 `log` |

## 4 · `conventions.md` 的找法（**别按号段猜主题**）

编号 `[K n]` 按分配顺序递增，但条目归入主题组。新条目追加到所属组，编号继续递增，因此同组编号不连续。每个 K 编号只定义一条约定；其它组出现的同编号是交叉引用。

- 阅读层级
  - `conventions.md`：主题 → K 条目 → 要点与边界。
  - 五个主题的导航在摘要开头，本文件不再复制。
- 定点查阅
  - 已知编号：`rg -n '^\- \[K156\]' docs/agents/conventions.md`。
  - 不知道编号：先锁定主题，再用条目标题搜索；具体实现回查对应模块契约与测试。
  - 已废止条目只保留编号和替代指针，不作为现行实现要求。
- **区间与引用由测试校验**（`agents-md-sync`）：日志里的「K1–K15x」是**历史批次读数**，不是当前范围。

## 5 · 常见误读（已踩过的）

- `index.md` 的规模表**不是**「谁该拆」的判据——拆不拆只看「收口点会不会被摊开」，与该文《文件规模与豁免》开头一致。
- `baseline-metrics.md` 的毫秒与体积是**某日实测**，跨日不可直接比；只比同轮相对值（该文 §2「读数解释」）。
- `testing.md` 里 `verify:visual` 的探针描述含历史加固记录，别据此推断当前实现仍有那些缺陷。
- 行数一律按 `countSourceLines`（`\n` 切分、末尾换行不计行）；`wc -l` 会少算，两者不一致是口径差不是漂移。
- 表格单元格里的 `|`（代码示例、正则、wikilink 尺寸）**必须写成 `\|`**，否则 GFM 会把它当列分隔符——由 `agents-md-sync` 的表格契约兜住。
