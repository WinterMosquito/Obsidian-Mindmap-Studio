# docs/agents 读取补充

> `AGENTS.md`「我要查 → 去哪」已给出**场景 → 文件**的 6 行简表，本文件不重复它。
> 这里只补五件简表没写的事：**规模**（要不要通读）、**权威边界**（冲突听谁的）、
> **文档义务**（改什么要同步哪份）、**`conventions.md` 的五组**（不必通读 1800 行）、
> **常见误读**（踩过的坑）。

## 1 · 规模：决定「通读」还是「定点查」

| 文件 | 规模（量级） | 建议读法 |
|---|---|---|
| `architecture.md` | ≈600 行 | 只读目录树里你要动的那几行（豁免表已收归 `AGENTS.md`，本文件不再复制） |
| `conventions.md` | ≈2200 行（~500 KB） | **禁止通读**；按 §4 的找法定位，或直接 `grep -n "\[K<编号>\]"` |
| `line-count-log.md` | ≈600 行 | 平时不读；追新批次记录或行数对账时只看首尾（新记录**追加到该文件**，不进 AGENTS.md） |
| `baseline-metrics.md` | ≈470 行 | 只读你要用来判回归的那一行；其余是历史读数 |
| `testing.md` | ≈200 行 | 改测试/CI 前读一遍；`verify:visual` 那段含历史加固，读「断言什么」即可；有 DOM 副作用的模块看「fake DOM 手法」小节 |
| `process.md` | < 100 行 | 发版前整读（短） |

规模只写到**量级**（一个数量级内不重排本表）：精确值用 `wc -l docs/agents/*.md` 现算，
口径差异见 §5 最后一条。

## 2 · 权威边界（先确认听谁的，再下结论）

| 信息类型 | 唯一源 | 其他位置怎么处理 |
|---|---|---|
| 规则结论 / 硬规则 / 决策表 | `AGENTS.md` | `conventions.md` 只存**理由与历史**，冲突以 `AGENTS.md` 为准 |
| 可漂移数字（规模 / 体积 / 性能 / 测试数） | `baseline-metrics.md` | 别处引用而不复制；引用前跑该行的复核命令 |
| 豁免表行数**终值** | `AGENTS.md`「文件规模与豁免」表 | `line-count-log.md` 只是批次流水（历史读数），冲突以终值表为准 |
| 行为 / 流程 / 证据交付 | 本机测试库 `00-开发支撑/Agent提示词.md` | 不进本仓库（公开仓库不写本机路径） |
| 实机验收读数 | 本机测试库 `10-wiki/事实快照.md` | 是**快照**；与实测冲突时以实测为准，回写并记 `log` |

## 4 · `conventions.md` 的找法（**别按号段猜主题**）

编号 `[K n]` 按分配顺序递增，但条目**被归入主题组**——新条目追加到「所属组」末尾、编号继续往大走，所以**同一组的编号不连续**，`K15` 可能同时出现在两个组里（引用的是不同条目）。

- 分组清单（5 行）**在该文件开头**，本文件不复制。
- 路径：读文件开头的组表 → 锁定组 → 在该组区间内 `grep "^- \[K"`。
- **区间与引用由测试校验**（`agents-md-sync`）：日志里的「K1–K15x」是**历史批次读数**，不是当前范围。

## 5 · 常见误读（已踩过的）

- `architecture.md` 的行数表**不是**「谁该拆」的判据——拆不拆只看「收口点会不会被摊开」，与该文《文件规模与豁免》开头一致。
- `baseline-metrics.md` 的毫秒与体积是**某日实测**，跨日不可直接比；只比同轮相对值（该文 §2「读数解释」）。
- `testing.md` 里 `verify:visual` 的探针描述含历史加固记录，别据此推断当前实现仍有那些缺陷。
- 行数一律按 `countSourceLines`（`\n` 切分、末尾换行不计行）；`wc -l` 会少算，两者不一致是口径差不是漂移。
- 表格单元格里的 `|`（代码示例、正则、wikilink 尺寸）**必须写成 `\|`**，否则 GFM 会把它当列分隔符——由 `agents-md-sync` 的表格契约兜住。
