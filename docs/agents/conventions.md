# 关键约定 K1–K216

- **用途与权威边界**
  - 本文按主题整理约定摘要与边界，K 编号保持稳定，供定点查阅。
  - 当前实现决策以 [decisions.md](decisions.md) 为准；Markdown 格式以 [标准文档](../markdown-mindmap-standard.md) 为准。
  - 本文保留当前约定与必要边界；已废止条目只保留稳定编号和替代指针，旧方案不作为实现要求。
- **定位方式**
  - 先按主题定位，再找 K 编号；同组编号不连续，编号不表示优先级。
  - 已知编号可用 `rg -n '^\- \[K156\]' docs/agents/conventions.md`，直接阅读该条要点。
  - K 编号不复用、不重编号；子编号继续保留。区间与全仓引用由文档契约测试校验。
- **维护方式**
  - 摘要采用「条目 → 要点 → 约定与边界」的多层 bullet，不展开调用链和测量流水。
  - 修改跨文件约定时更新决策与摘要；单文件实现细节写在源码契约中，不另建排查历史档案。
  - 维护义务的唯一清单见 [process.md](process.md#文档维护规则与同步义务)，日常维护不改稳定入口 AGENTS.md。
- **按主题定位**
  - 链接、图片与 Markdown 保真：解析、引用、编辑与回写。
  - 引擎行为、视口与布局：引擎调用、画布几何与布局行为。
  - 架构边界与单一来源：分层、能力收口与文档会话。
  - 交互对齐 Obsidian 官方：快捷键、菜单与无障碍。
  - Obsidian API 合规与工具链：API、渲染、门禁与重构。

## 链接、图片与 Markdown 保真

- [K1] **新引用跟随 Obsidian 偏好**
  - 要点
    - 新增链接遵循宿主的双链开关与新链接路径设置；文档链接和图片引用共用路径生成入口。
    - 同名消歧发生在写引用时，存量引用不因后来出现同名文件而改写。

- [K2] **Markdown 内容与视图偏好分开存储**
  - 要点
    - 正文保留标准 Markdown；启用与布局由文件属性承载，视口、连线、配色和边框偏好按文件存储。
    - 早期把布局写入视图状态的方案已退役；当前属性契约见 K14、K213。

- [K3] **行级原文与短横线语义**
  - 要点
    - 原文保留行内空白、缩进代码和硬换行；显示文本与原文分别保存。
    - 短横线的分隔线与 setext 标题身份按解析器契约区分，不在渲染层重新解释。

- [K4] **文档嵌入与附件嵌入**
  - 要点
    - 文档嵌入与双链共用文档通道；别名控制显示名，附件参数保留原文。
    - 文档、附件和图片的分类共用已有判据，导航与悬停采用同一分流。

- [K5] **双链解析的能力边界**
  - 要点
    - 空双链保留字面文本；路径、子路径与别名分开处理，导航交给 Obsidian。
    - 引擎单链接槽位与自绘逐枚交互分开处理，见 K53、K117。

- [K6] **纯双链节点编辑别名**
  - 要点
    - 纯双链节点的显示名、回写别名与图标提示共用同一判据；清空别名仍保留目标。
    - 混合文本、多行、附件、URL 和含非法方括号的别名不套用纯双链规则。

- [K7] **混排双链拆分**
  - 要点
    - 显式批量命令与可选的编辑后自动拆分共用规划逻辑；自动拆分默认关闭，见 K117。
    - 候选来自编辑期捕获，不以检查时的选中节点替代；解析和幂等规则留在模块契约。

- [K8] **图片尺寸写入 Markdown**
  - 要点
    - 用户指定或拖拽改变的尺寸回写宿主图片语法，不另存一份尺寸偏好。
    - 加载时探测出的显示尺寸不回写；无参数图片的展示口径见 K97。

- [K9] **纯图片节点与移除语义**
  - 要点
    - 纯图片节点不补文件名文字；移除图片或链接后，原文残留不能使内容复活。
    - 同行其它图片保留；图片嵌入与文档、附件链接分别处理。

- [K10] **图片与链接的宿主语法**
  - 要点
    - 库内双链、图片嵌入及悬停预览沿用宿主能力；合成外链图片使用 Markdown 图片语法。
    - 更换图片后的地址取当前值，不使用解析时的旧地址。

- [K11] **中心主题与文件名关联**
  - 要点
    - 当前中心主题仍取文件名；编辑声明为导图的根节点可重命名文件，外部改名同步主题。
    - 重命名走 FileManager 以更新库内引用；本批文档整理不改变这项产品行为。

- [K12] **显示层不修补解析结果**
  - 要点
    - 显示名直接消费解析层产物；渲染、悬停和提示不各自补一套字符串修正。
    - 需要改变显示语义时，先核对解析、原文保真及纯链接判定的共同契约。

- [K13] **显示反馈与语法事实隔离**
  - 要点
    - 图标、提示和悬停属于显示层，不能借此改写节点的嵌入语法事实。
    - 附件通道字段变化须一起核对序列化与别名解释。

- [K14] **导图启用与布局的唯一判据**
  - 要点
    - 启用属性与布局属性职责分开；只识别当前启用信号和当前短布局 id。
    - 判定集中于 domain/mindmap-property；早期单键布局枚举和历史迁移由 K213 取代。

- [K45] **保存使用当前文件头**
  - 要点
    - 写盘时保留磁盘最新 frontmatter，不用加载快照覆盖属性面板或其它视图的修改。
    - 当前写入走原子读改写；正文与文件头的空行见 K176。

- [K46] **frontmatter 切分保真**
  - 要点
    - 空属性块、BOM、块标量内的短横线及 CRLF 都按原文保留。
    - 不能用遇到第一条短横线就结束的简化切分破坏 YAML。

- [K47] **添加链接不覆盖已有内容**
  - 要点
    - 完全空白节点可承载新链接；已有文字、图片或链接时，新链接作为子节点。
    - 弹窗与拖入共用内容判据，改链可通过原文编辑或先清除再添加。

- [K48] **引用定义行保留全文**
  - 要点
    - 链接引用与脚注定义属于语法基础设施，解析和拆分不抽走其目标内容。
    - 脚注引用的只读交互另见 K197，定义行仍保留为节点。

- [K49] **多 token 使用单一台账**
  - 要点
    - 多链接、多 URL 与多图片的额外原文统一登记，编辑后不丢内容或语法。
    - 拆分重建台账；清除链接不误删图片段；原位对齐见 K52。

- [K52] **编辑后的 token 尽量保留原位**
  - 要点
    - 按显示段与原文对齐恢复 token，命中时使用当前链接与尺寸。
    - 对不上时保留原文并尾插，不猜测替换，也不嵌套进用户新写的链接语法。

- [K55] **删除文档不清除引用**
  - 要点
    - 删除笔记保留未解析链接，重建同名文件可恢复；重命名继续更新引用。
    - 附件删除按既定内容移除契约处理，不能只清字段留下可见名。

- [K56] **链接交互对齐宿主**
  - 要点
    - 点击修饰键、未解析目标、悬停与拖放按官方帮助分流。
    - 官方帮助缺少的导航历史行为用 API 与宿主实测补证，见 K111。

- [K54] **弹窗编辑的模式边界**
  - 要点
    - 纯链接节点可编辑可见名，其它富节点编辑即将回写的原文并显示预览。
    - 日常节点编辑已使用内联通道，见 K92；弹窗模式不替代保存判据。

- [K53] **富节点由插件自绘**
  - 要点
    - 轻标记、逐枚链接与图片等呈现由自绘通道提供，解析和回写继续遵守 Markdown 契约。
    - DOM、局部样式与段模型已按 K209 拆分；解析器不移入 UI。

- [K71] **Markdown 往返达到不动点**
  - 要点
    - 规范化在允许范围内收敛；空标题、空列表及原文结构不能静默丢失。
    - 等价级别与规范化白名单唯一维护于 Markdown 标准文档。

- [K156] **纯浏览不写盘**
  - 要点
    - 加载后记序列化基线，未编辑时跳过规范化写盘。
    - 本会话已写过盘后撤销回加载态，须写回加载原文，不能再按纯浏览跳过。

- [K158] **自动保存收尾核对活快照**
  - 要点
    - 真正写盘的自动保存轮次收尾比较当前内容，不一致时有界补排。
    - 失败、无差异跳过与显式收尾不制造额外重试风暴。

- [K164] **列表缩进随文件**
  - 要点
    - 从正文实测缩进单位，回写保留 Tab、空格及合法混合单位。
    - 列表归层与 YAML 缩进使用不同判据；无实测值时使用既定默认。

- [K176] **文件头与正文间空行保留**
  - 要点
    - 写盘保留磁盘当前文件头及其与正文之间的原样空白。
    - 这部分不参与正文脏判据，撤销回原文也不能重复拼接空行。

## 引擎行为、视口与布局

- [K15] **默认视口与手动总览**
  - 要点
    - 无保存视口时按内容居中并使用 100% 缩放；有保存视口则恢复。
    - 重置缩放以画布中心为锚点；整理通常保留视野，切布局的整理另做总览。

- [K16] **连线样式只有折线与曲线**
  - 要点
    - 全局默认、按文件偏好和渲染归一共用选项来源。
    - 布局固有直线时开关置灰，不丢用户偏好；读取非法值按当前默认处理。

- [K17] **根节点连线衔接**
  - 要点
    - 曲线从根节点边缘平顺展开，避免从节点内部斜穿边框。
    - 通过主题配置表达，不另写连线绘制逻辑。

- [K18] **切布局后整理**
  - 要点
    - 切换布局清除旧自由坐标并在新布局落地后取总览。
    - 异步窗口中的安全判据见 K67；常规结构拖动不做全图整理，见 K205。

- [K19] **命令不设默认热键**
  - 要点
    - 发布命令保留用户配置空间，不注册默认快捷键。
    - 视图内系统编辑快捷键属于视图作用域，见 K38。

- [K20] **无差异不写盘**
  - 要点
    - 序列化结果与写盘基线一致时跳过修改。
    - 纯浏览还须使用加载基线，不能只拿规范化结果与磁盘比较，见 K156。

- [K21] **悬停预览走宿主事件**
  - 要点
    - 注册悬停来源并派发宿主 hover-link，文档和附件共用导航分流。
    - 链接目标和打开方式沿用宿主语义。

- [K22] **菜单开启编辑的事件时序**
  - 要点
    - 从右键菜单进入引擎编辑时，延后开启以避开菜单点击的外部关闭事件。
    - 保留一次开启，不让同一点击立即关闭新编辑面。

- [K23] **已废止：插件侧拖拽换父辅助**
  - 要点
    - 旧的独立落点模块、判定和事件循环不再恢复。
    - 当前邻近吸附在引擎补丁中实现，见 K205。

- [K24] **承载内容的新节点统一入口**
  - 要点
    - 拖入、粘贴与添加图片等新建承载节点动作共用插入适配。
    - 统一父节点与激活参数，避免入口各自拼接引擎命令。

- [K25] **引擎访问经防腐层**
  - 要点
    - 引擎内部数据、搜索、导出和节点形态由 engine/mindmap 的具名接口收口。
    - 特性层不能直接读取 renderer 或节点内部 DOM。

- [K26] **引擎命令名集中定义**
  - 要点
    - 引擎命令使用统一常量，拼写及可用命令由类型检查约束。
    - 不在业务模块散落字符串命令名。

- [K26b] **整树修改与快照投影分开**
  - 要点
    - 整树编辑要保留撤销链；直接重置引擎数据会清空历史。
    - Level B 的跨视图投影采用无回声快照通道，见 K181；撤销权威属于文档会话。

- [K26d] **自绘节点调宽必须完成内容重测**
  - 要点
    - 拖宽不仅更新外框，还要让自绘内容消费新宽度并在收尾重测布局。
    - 高频预览与最终提交分开，见 K26e。

- [K26f] **活数据与深拷贝快照不可混用**
  - 要点
    - 引擎节点数据是活引用，整树数据出口是深拷贝；调用方须按职责使用。
    - 防腐层和测试保留这一区别，不能把活引用当不可变快照。

- [K26g] **高频路径控制重复成本**
  - 要点
    - 缓存逐项淘汰，避免满表清空；同一行原文复用解析结果；设置应用防抖。
    - 数值和实现细节由现有常量、模块契约及性能基线维护。

- [K26h] **图片树必须先补默认尺寸**
  - 要点
    - 任何先显示再异步探测的图片路径，都须先提供引擎可解构的尺寸。
    - 初次创建和会话快照两条入口均须覆盖，见 K198。

- [K26i] **保留自绘内容接管**
  - 要点
    - 自绘承担统一呈现与编辑契约；拖动和缩放不应重建内容，单节点编辑只重建受影响内容。
    - 历史成本测量属于证据，不凭虚拟时钟耗时决定缩减接管面。

- [K26e] **拖拽预览不逐帧提交**
  - 要点
    - 图片等尺寸拖动只更新显示预览，松手后提交一次真实变化。
    - 中途不加历史、不发内容变更、不排保存；拖回原尺寸不提交。

- [K216] **画布热键拖拽设置只改变原生起手判据**
  - 要点
    - `dragCanvasWithModifier` 缺省开启：空白左拖框选、Cmd/Ctrl 左拖平移；关闭时两者互换。右键框选/选区菜单、中键平移与滚轮缩放保留。
    - 起手时锁定手势，松开热键或中途切换设置不改变当前操作；下一次起手读取新值。节点起手不变画布平移，开启时 Mod 节点拖动不改结构；普通节点拖动仍归原生 Drag。
    - 设置经既有 sanitize/持久化/差集刷新管线，经 engine 的具名入口原地 updateConfig，不重建引擎、不改共享文档会话/历史/Markdown。
    - vendor 补丁仅改 Event/View/Select/Drag 原判据，禁止新增插件侧平移或框选循环；只读嵌入无选择/编辑插件。纯逻辑与独立 Chrome 页面覆盖两档设置、双修饰键、缩放和独立 Window。

- [K26c] **画布手势各有一个实现**
  - 要点
    - 引擎负责缩放与中键拖动；插件只补宿主中键抑制、Alt 横移和平滑滚动。
    - 同一手势不能同时注册两套平移处理。

- [K27] **vendor 通过补丁流程维护**
  - 要点
    - vendor bundle 不手改；修改补丁后重新打包并同步哈希契约。
    - 插件样式不引入上游 Quill CSS；引擎样式由运行时注入。

- [K64] **首帧视口须等几何稳定**
  - 要点
    - 默认居中避开旧容器尺寸与中间态；图片尺寸回灌后核对内容可见性。
    - 常规和性能模式各按既有路径取几何，不为居中强制装配全量 DOM。

- [K130] **导出数学内联字体**
  - 要点
    - 独立导出补入数学字体，使完整公式不依赖宿主页面中的字体加载状态。
    - SVG 内容存在不等于 PNG 光栅化完整，需核对实际导出产物。

- [K131] **逐帧位置更新不叠 transition**
  - 要点
    - 小地图视口框等逐帧定位元素直接跟随计算结果。
    - CSS 动画不能制造落后于真实几何的第二条运动曲线。

- [K132] **布局完成后采样**
  - 要点
    - 切布局等异步重排先等渲染落地，再取缩略图和几何。
    - 样式变化可立即刷新，两类入口不能混为一个。

- [K133] **小地图连线与方块分预算**
  - 要点
    - 连线是否绘制按全量节点数和深度判断，节点方块数量按标记上限采样，两者分别约束。
    - 不能以采样后的数量决定连线门槛；具体限额由几何模块契约维护。

- [K134] **小地图帧指纹包含结构标记**
  - 要点
    - 等价帧判定除外框，还包括布局、连线及节点颜色等呈现指纹。
    - 外框一样不代表图像未变化。

- [K135] **小地图悬停保活与滚轮转发**
  - 要点
    - 悬停小地图期间保活；滚轮转发到画布，沿用同一缩放与平移语义。
    - 停用面板时复位悬停状态；跨窗口转发取所属窗口的事件构造器。

- [K136] **小地图连线按布局生成**
  - 要点
    - 缩略图复刻各布局的连线结构，不用一个猜主轴模型替代。
    - 映射与几何算法唯一维护于既有小地图模块。

- [K137] **会话唤醒与拆卸的时机**
  - 要点
    - 用户手势可唤醒小地图，后台渲染只续期已显示面板；淡出后换图不重新显示。
    - 切文件时的会话拆卸先于 await，避免旧操作回来后误拆新会话。

- [K138] **Alt 滚轮横移**
  - 要点
    - 插件只接管引擎缺少的 Alt 横轴语义，其余滚轮分支保留原职责。
    - 幅度和方向由现有手势契约统一计算。

- [K215] **缩略图在右侧 Outline 内常驻**
  - 要点
    - 主窗口只暂借一枚右侧 Outline 的公开容器，保留核心视图/状态；来源为同窗口最近的主内容导图，侧栏获焦不切源。离开导图或卸载时还原原内容及控件，其它侧栏页签和 tag 面板不动。
    - 小导图也显示全图；复用原取样/SVG/视口投影/拖拽/滚轮，同一组件迁移而非重建导航。侧栏按可用尺寸等比居中，渲染事件短节流刷新，平移缩放仅更新框；隐藏或折叠暂停取样，不主动展开或切走其它页签。
    - 唯一未公开契约是核心 view type `outline`，防御边界及自有 ItemView 回退见决策表；popout 无官方侧栏 API，继续使用原窗口浮层，不借主窗口文档。浮层启用/淡出规则仍保留。

- [K140] **视口框读取实时画布尺寸**
  - 要点
    - 投影使用当前画布宽高，绘制快照仅用于内容与面板几何。
    - 改窗口后不能长期等待下一次整图刷新才纠正视口框。

- [K141] **鱼骨小地图保留骨架**
  - 要点
    - 水平骨干、短骨与斜脊按鱼骨布局实际几何生成。
    - 不套用通用树连线导致缩略图结构失真。

- [K142] **无选中复制整图大纲**
  - 要点
    - 有选中复制子树；无可复制选中项时复制含中心主题的整图。
    - 只选中根时也使用整图分支。

- [K143] **竖栏组内分隔对齐 Canvas**
  - 要点
    - 分隔线在条目上表达，按钮间距、圆角与 tooltip 使用既定宿主样式。
    - 样式归组件目录，旧穿透层不能刷满画布背景。

- [K144] **鼠标滚轮平移平滑**
  - 要点
    - 格状滚动在帧内趋近目标，触控板小增量与缩放仍按原手势分流。
    - 停用、切引擎或销毁时取消帧工作。

- [K145] **节点颜色指令属于正文**
  - 要点
    - 顶层颜色注释是颜色来源；自身覆盖最近祖先，再回落文件配色。
    - 代码、数学等保护区不识别；派生引擎样式不回写为第二份内容。

- [K146] **节点与整图配色入口分开**
  - 要点
    - 节点右键写正文颜色指令，空白右键改整图配色偏好。
    - 边框宽度仍由边框开关决定，小地图读取节点实际描边色。

- [K147] **小地图动作后显式刷新**
  - 要点
    - 插件内样式、结构与布局操作使用对应刷新入口。
    - 后台节拍是兜底，不能让明确操作等待下一次节拍。

- [K148] **图片探测失败缓存可失效**
  - 要点
    - 同一会话不重复轰炸失败地址；重新打开时让资源有再次探测机会。
    - 失败仍提供安全尺寸，不能把一次暂时失败当永久不可用。

- [K149] **显式默认颜色阻断继承**
  - 要点
    - none 哨兵使该节点和后代回到整图配色；无祖先色可挡时直接删自身指令。
    - 哨兵留在 Markdown，跨窗口或设备仍有同样语义。

- [K165] **画布几何来自布局数据**
  - 要点
    - 包围盒与缩略图几何使用引擎布局坐标，不把 DOM 是否挂载当节点是否存在。
    - 性能模式不能因离屏节点未装配而漏掉内容。

- [K167] **节点颜色作用范围写入内容**
  - 要点
    - 仅本节点与含子节点通过正文指令和哨兵表达，渲染层不另存作用范围。
    - 切设置只改变后续动作；已有哨兵清理须用户选择，见 K175、K192。

- [K168] **层级语法保持往返结构**
  - 要点
    - 正文决定当前语法与标题起点；新图设置只初始化空文档，显式重排按兄弟组原子执行。
    - 列表在前、标题在后的同级混排合法；只归一会改变重解析结构的排布。

- [K169] **标题拖入列表整支降级**
  - 要点
    - 落点是列表父时，整支改为列表并保留内容，和拖拽共享一次撤销。
    - 标题锚点可能失效，提示统计见 K178；段落父的防御边界单独处理。

- [K170] **语法切换保留元数据**
  - 要点
    - 整支转列表时段落也转成承载项；有序编号保留，列表 marker 在会话内可恢复。
    - 写成标题后文件中不再有 marker，重开不承诺恢复该会话记忆。

- [K171] **层级语法的可达边界**
  - 要点
    - 防御分支先按解析、结构守卫及粘贴入口判断用户能否到达。
    - 当时段落父掉层的问题已由 K179 修复；不将历史未修列表当当前缺陷。

- [K172] **兄弟风格按插入位置继承**
  - 要点
    - 新节点位于该层最后一个标题之后时，不因前面有列表而误写成该标题的子项。
    - 起点以本文件实测语法为准，保留合法前列表后标题的混排。

- [K174] **标题的颜色指令独立成行**
  - 要点
    - 给标题上色把指令放在下一行，避免宿主标题缓存把指令算进锚点。
    - 已有行尾指令保留原文；内容写法及指令清除共同核对。

- [K175] **改作用范围不自动删正文哨兵**
  - 要点
    - 从仅本节点改为含子节点时，询问是否清理当前打开文档中的旧哨兵。
    - 用户确认后重新扫描并核对文件归属；按文档只处理一次，见 K192。

- [K177] **已取代：多视图后关闭者胜**
  - 要点
    - 同文件视图共享权威会话，不能各写各的正文。
    - 当前同步与外部冲突见 K180、K182。

- [K178] **降级提示统计标题锚点**
  - 要点
    - 提示整支实际失去锚点的标题数，并明确可撤销。
    - 不扫描全库引用，不能把标题数说成受影响链接数。

- [K179] **段落父回写为列表承载**
  - 要点
    - 段落有子节点时按列表项输出并补正确缩进，保住重解析层级。
    - 普通解析中的叶子段落保持原形，不为浏览改写文件。

- [K195] **视图状态只写真实变化**
  - 要点
    - 同值不排写盘，未动过的自动默认视口不保存；关闭前先持久化再重置控制器。
    - 同文件其它视图保存的视口不能带跑本视图；不批量清理历史默认条目。

- [K196] **callout 与引用块只做呈现**
  - 要点
    - 引用、围栏、表格、行内内容按块级顺序解析，再交 UI 渲染。
    - 保护区不识别引用；折叠与类型归一遵循宿主语义，原文不因显示变化而改写。

- [K199] **编辑文字与底色跟随节点**
  - 要点
    - 编辑面保留当前节点的字号、文字色与底色，使编辑状态自然衔接。
    - 当时固定尺寸与内部滚动方案已由 K203 替代。

- [K200] **空白连续点击不创建节点**
  - 要点
    - 空白单击与双击只保持选择或清空行为，不新增根级空节点。
    - 新建仍由明确命令、菜单、Tab、Enter 或加号进入。

- [K203] **原文编辑自适应尺寸**
  - 要点
    - 编辑面按文本测宽，达到宽度上限后换行并显示完整高度，不产生内部滚动条。
    - 预览只改编辑 DOM；暂藏原节点，关闭恢复，提交才更新树、历史和保存。

- [K204] **两种编辑面统一高亮职责**
  - 要点
    - 引擎空节点编辑和插件原文编辑暂藏旧节点，由编辑面自身绘制外框及高亮。
    - 高亮随尺寸变化；关闭、缩放、替换与销毁都恢复原可见状态。

- [K205] **结构拖动邻近吸附**
  - 要点
    - 只改变父子结构与顺序；精确命中优先，再给可见邻近目标屏幕容差，松手核对最终位置。
    - 未命中回原位，不留下自由坐标、不做全图整理、不改变视口；判定在引擎补丁中。

- [K206] **常驻整理按钮移除**
  - 要点
    - 结构拖动自动归位后，右侧不再常驻整理按钮。
    - 右键和命令仍保留显式整理能力。

- [K201] **新图只含中心主题**
  - 要点
    - 初始 Markdown 只写启用与布局属性，正文为空，不预置示例分支。
    - 首个节点语法按新图设置一次初始化，后续由正文自身决定。

## 架构边界与单一来源

- [K28] **通用判定与并发原语唯一**
  - 要点
    - URL、解码、扩展名与并发机制复用对应公共模块。
    - 批量异步任务使用有界并发；解码失败由调用方显式选回退或跳过。

- [K28b] **复制链接共用文件写法**
  - 要点
    - 序列化与复制链接使用同一渲染出口，剪贴板内容须能直接粘回 Markdown。
    - 文件夹查找共用入口；跨 await 写入核对原会话和引擎归属。

- [K29] **库内文件解析统一入口**
  - 要点
    - 路径查找与索引操作经 links 层既有收口，业务模块不拼自己的扫描链。
    - ESLint 与真实依赖图共同检查边界。

- [K30] **Vault 事件统一订阅**
  - 要点
    - 创建、删除、重命名由同步服务单点订阅，补充行为经 hooks 注入。
    - 同一事件不因新特性增加第二份订阅。

- [K31] **特性模块通过上下文访问能力**
  - 要点
    - 视图特性只拿设置、状态服务等所需能力，不持有插件实例或共享状态栏 DOM。
    - 局部节点、悬停与会话状态在所属模块内聚。

- [K32] **上下文保持窄接口**
  - 要点
    - 模块按需组合 DOM、引擎与少量视图字段，不默认接受整个装配面。
    - 新成员先明确属于哪个子契约。

- [K33] **错误与告警格式统一**
  - 要点
    - 用户可见错误、消息提取与内部去重告警复用 core/errors。
    - 用户不可见的能力退化仍留痕；去重范围由告警实例的生命周期决定。

- [K34] **占位文案统一格式化**
  - 要点
    - 带参数的国际化文案使用统一格式化入口。
    - 不逐处手写替换链；中英文词条同时维护。

- [K35] **弹窗收尾与文件联想复用**
  - 要点
    - 弹窗 Promise 只完成一次；关闭兜底与库内文件联想使用公共实现。
    - 关闭回调使用宿主注册方式，避免覆写生命周期方法。

- [K36] **监听与定时器随生命周期清理**
  - 要点
    - DOM、宿主事件、定时器与引擎事件统一登记，在卸载时释放。
    - 不留下模块外无法追踪的监听器。

- [K37] **项目命名保持一致**
  - 要点
    - 当前插件、设置与设置页使用 MindMap Studio 的统一命名。
    - 历史品牌名只作记录；更名应作为单独任务处理。

- [K50] **模块化的四条边界**
  - 要点
    - 单一职责、分层单向、能力收口唯一、模块接口最窄。
    - 新职责先找所属模块；是否拆分由职责判定，不按行数机械切割。

- [K51] **依赖矩阵只有一个来源**
  - 要点
    - scripts/module-boundaries.mjs 同时驱动 lint 和真实依赖图测试。
    - 新组先定层；组内禁止成环；子目录不增加新的依赖许可。

- [K166] **保存状态有一个判据**
  - 要点
    - 共享保存管线报告内容是否落盘，活动视图负责写共享状态栏。
    - 保存错误保持未保存提示，下一次成功恢复；加载与应用快照不空报保存中。

- [K173] **mermaid 使用宿主同款渲染器**
  - 要点
    - 平台层负责 npm 内嵌渲染器的加载与渲染，UI 只消费注入能力。
    - 它作为锁版本依赖打包，不进入仅存补丁 bundle 的 vendor 目录。

- [K180] **一文件一文档会话**
  - 要点
    - 同文件视图共享权威树、撤销时间线和保存管线；各自保留引擎与视口。
    - 编辑经会话广播，视图只是投影，不建立各自独立写盘权威。

- [K181] **快照投影不产生回声**
  - 要点
    - 跨视图应用只走无历史、无内容变更事件的快照入口。
    - 不能用会追加历史的普通整树更新替代，也不靠临时暂停吞掉事件。

- [K182] **外部写入优先保留磁盘新内容**
  - 要点
    - 写盘前发现磁盘正文变更，放弃陈旧写入并重载；草稿保留为可撤销快照。
    - 有草稿提示一次，无草稿静默；不做未经授权的树级合并。

- [K183] **关闭保存由会话负责**
  - 要点
    - 内容变化两秒防抖，关闭、切文件及卸载立即 flush；同文件只有一条保存管线。
    - 内联编辑必须先提交，再停用提交入口和释放视图。

- [K184] **会话订阅与重命名迁移**
  - 要点
    - 重命名迁移会话注册键，不重建各视图引擎；订阅与合并广播按会话生命周期管理。
    - 所有路径基线也须迁移，补充修复见 K194。

- [K185] **广播延迟按图规模选择**
  - 要点
    - 小图立即广播，大图使用短合并窗口，跳过已持有最新内容的发起视图。
    - 默认装配不得无条件注入延迟而使分流失活，见 K194。

- [K186] **广播收尾与撤销一致**
  - 要点
    - 撤销、重做及外部重载广播给所有视图；应用前先完成本地编辑，避免最后输入被守卫丢弃。
    - 所有视图保持同步渲染；当时跳过隐藏标签的优化已回滚。

- [K187] **已废止：一次性历史属性迁移**
  - 要点
    - 不再在启动时识别、改写或清洗旧声明。
    - 当前只实现现行数据契约，见 K213。

- [K188] **就地归一同步权威树**
  - 要点
    - 语法守卫修改 Markdown 字段后，同步当前会话快照但不新增撤销历史。
    - 不让下一轮广播拿旧权威树覆盖已归一的字段。

- [K189] **视图撤销方法保持同名契约**
  - 要点
    - 视图的 undo 与 redo 明确委托会话，所有入口使用同一时间线。
    - 不能因适配命名不匹配而静默回退引擎历史。

- [K190] **打开不空保存、不重复投影**
  - 要点
    - 只有实际内容提交才排保存；已用当前会话树建好的引擎不再重放同版本。
    - 初始化期间若确有新版本仍须补应用。

- [K191] **图内链接覆盖所有点击通道**
  - 要点
    - 正文、标签、双链等相关入口一起覆盖，事件目标按元素能力判定。
    - popout 是另一 realm，不使用本窗口 instanceof 判断排除合法目标。

- [K192] **哨兵清理按文档去重**
  - 要点
    - 同文件多视图只计一次提示、扫描与提交。
    - 确认后的重新检查使用共享文档状态，不能按每个 leaf 重复清理。

- [K193] **豁免与门禁定义唯一**
  - 要点
    - 超限文件只登记于 index；门禁显式覆盖配置与打包面依赖。
    - 批次流水保存历史值，不复制当前豁免表。

- [K202] **稳定入口与可变维护分开**
  - 要点
    - AGENTS.md 保留固定规则与导航，索引、决策、理由和流水归 docs/agents。
    - 日常清单、行数与批次记录不触发入口文档重写。

- [K194] **会话广播与改名基线完整**
  - 要点
    - 拒绝落后视图的整树提交并回刷权威树；改名迁移保存基线；应用期间不重复排保存。
    - 不做树级合并或跨进程同步；用真实装配与关闭顺序验证。

## 交互对齐 Obsidian 官方

- [K38] **视图快捷键与宿主交互**
  - 要点
    - 视图自行创建作用域，接管编辑、撤销与剪贴板动作，并在输入面内让位。
    - 撤销和重做由文档会话驱动，见 K180、K189；附件命名及打开方式对齐宿主。

- [K139] **小地图无障碍语义**
  - 要点
    - 小地图面板保留 group 角色，不加 aria-label，避免宿主把它显示为可见 tooltip。
    - 如需恢复面板名称，使用 aria-labelledby；控件本身仍须有明确可访问标签。

- [K150] **任务与标签从正文派生**
  - 要点
    - 任务 token、标签及交互走自绘通道，不写引擎 tag、note 或 icon 的第二份数据。
    - 原文与显示文本分开，复选状态更新沿用正文提交机制。

- [K151] **标签与任务使用宿主链接色**
  - 要点
    - 标签 pill 与任务复选框的颜色与 wiki 链接同源。
    - 着色节点内的可读性按派生内容色契约处理。

- [K152] **离屏测量残渣隔离**
  - 要点
    - 渲染完成后清理测量副本，容器排除无障碍树和键盘焦点。
    - 清理不能干扰下一轮测量；不可只等引擎销毁才处理。

- [K153] **删除联系回收无主身份**
  - 要点
    - 删边或删源节点后，目标再无入边时移除它的身份指令。
    - 清理与主动作合为同一次原文提交，仍有引用时保留身份。

- [K154] **联系线颜色使用统一来源**
  - 要点
    - 联系线颜色写在联系指令属性中，线的右键菜单复用节点色族与自定义颜色入口。
    - 只覆盖颜色，线宽、虚线、字号仍由主题管理；选中高亮保持独立语义。

- [K155] **右键菜单只显示一份**
  - 要点
    - 插件节点、画布和选区菜单确定归属后阻止宿主重复弹菜单。
    - 右键拖动的分流另见 K163。

- [K157] **长耗时导出有可见反馈**
  - 要点
    - 导出期间展示进度或忙碌状态，结束与失败均收尾。
    - 反馈覆盖实际异步阶段，不能仅在开始时闪一下。

- [K159] **两态开关提供按下状态**
  - 要点
    - 连线、边框等开关的可访问状态随实际偏好更新。
    - 不只靠图标或 tooltip 表达当前值。

- [K160] **撤销能回到打开原样**
  - 要点
    - 首帧落地后建立初始历史；第一次编辑必须可撤销到加载状态。
    - 回到加载态还须正确写回原文，见 K156；Level B 的权威撤销线见 K180。

- [K161] **大图初始化有可见反馈**
  - 要点
    - 长首帧任务期间显示正在构建，完成或失效时结束反馈。
    - 无报错且空画布不等于已完成初始化，自动化还须核对可见性和引擎就绪。

- [K162] **概要锚定首个被覆盖兄弟**
  - 要点
    - 概要覆盖从锚点开始的连续兄弟，边界与重叠按已有契约解释。
    - 指令块语法统一，显示派生不制造另一份正文；具体格式见标准文档。

- [K163] **右键拖动后的菜单分流**
  - 要点
    - 框到节点显示选区菜单，未框到不弹菜单；普通右键继续按落点处理。
    - 拖动判断在事件链结束前记录，不能松手后再问已清空的引擎选择状态。

## Obsidian API 合规与工具链

- [K39] **官方 API 优先**
  - 要点
    - 优先使用官方声明与帮助文档；确有缺口的私有触点须防御式实现并登记。
    - 历史审计的数量不作当前清单；实际触点与防御边界见对应模块契约及决策表。

- [K40] **最低宿主版本有功能依据**
  - 要点
    - 最低版本须覆盖实际使用的声明式设置等 API，不能只为发布元数据调整。
    - 安装的类型版本、最低运行版本与参照文档版本分别核对。

- [K41] **设置对象键须核对版本**
  - 要点
    - 新增声明式设置字段时人工检查其引入版本。
    - 对象字面量的键不由现有 API lint 完整覆盖，编译通过不等于最低版本可用。

- [K42] **桌面限定影响正则可用性**
  - 要点
    - 移动端支持或变更桌面限定前，先审查并替换依赖后行断言的正则。
    - 须覆盖序列化与轻标记扫描，并执行完整往返回归。

- [K43] **lint 在插件根目录执行**
  - 要点
    - 部分宿主 lint 规则按工作目录读取 manifest，运行位置是检查契约的一部分。
    - 从父目录执行可能改变桌面判据与全局环境。

- [K44] **API lint 的有效边界**
  - 要点
    - 最低版本阈值显式来自 manifest；可检查的 API 上沿来自项目安装的 typings。
    - 调整类型依赖时重新核对规则与缓存，不拿最新在线文档当实际检查上沿。

- [K57] **死代码检查保留测试入口**
  - 要点
    - 无用途文件与导出去除；纯逻辑直测所需的导出仍算有效入口。
    - 检查配置包含测试，不凭仅生产入口的对照报告机械删除。

- [K58] **历史测量：单次编辑成本**
  - 要点
    - 文本尺寸变化需要布局重排；插件首先消除无必要的重复渲染。
    - 计数与耗时分别验证；当前性能基线以同轮测量为准。

- [K59] **设置按键差集应用**
  - 要点
    - 设置变化只触发受影响的主题、界面或引擎能力，避免一律重建。
    - 后续收敛见 K60、K62；现行键集由设置刷新实现维护。

- [K60] **性能模式原地更新**
  - 要点
    - 支持原地更新的性能配置不重建引擎，保留视口与编辑上下文。
    - 配置更新后的重渲染只付一次，不重复销毁并重建实例。

- [K61] **一次动作至多一次布局落地**
  - 要点
    - 先批量写入数据，再统一安排布局；不让多个适配重复触发整树渲染。
    - 对计数与真实耗时分别验证，不能互相替代。

- [K62] **历史收敛：设置刷新范围**
  - 要点
    - 可原地更新的设置不重建；不影响当前文件的默认值变化不刷新当前图。
    - 现行重建键集唯一维护于设置刷新入口，不在文档复制易漂移的清单。

- [K63] **真实性能使用真实时钟**
  - 要点
    - 耗时结论采用真实墙钟通道，虚拟时钟只用于结构及次数断言。
    - 历史毫秒读数不可直接当当前门槛。

- [K65] **历史测量：长会话内存**
  - 要点
    - 历史快照是需重点约束的内存来源，测试须验证实际保留深度。
    - 共享会话后的撤销归属见 K180，内存结论须按当前会话模型复核。

- [K66] **历史深度按预算收敛**
  - 要点
    - 撤销链使用既有内存预算与图规模限制，不无限保留整树快照。
    - 当前共享历史由会话管理，不沿用旧的每视图独立历史模型。

- [K67] **整理避开 root 未就绪窗口**
  - 要点
    - 异步布局进行时不对缺失的渲染根执行整理命令。
    - 收尾等待与回退在引擎控制层统一处理，不由按钮各自补逻辑。

- [K68] **历史优化：索引、拖拽与接管缓存**
  - 要点
    - 减少全库重建、逐帧分配与重复自绘判定。
    - 旧拖拽辅助已退役，见 K23；不为性能优化恢复已删除的业务路径。

- [K69] **资源解析先走低成本路径**
  - 要点
    - 可直接解析的资源不先建全库索引，纯文本解析使用快路径。
    - 快路径必须与完整路径保持语义一致，已有回归共同覆盖。

- [K70] **居中不强制装配全图 DOM**
  - 要点
    - 大图默认居中从布局数据计算几何，避免临时关闭性能模式。
    - 常规与性能模式共同满足内容可见性契约，性能读数须重新测量。

- [K72] **历史测量：文本测量成本**
  - 要点
    - 大图成本分析先区分引擎逐字符测量与插件内容构建。
    - 不按未经验证的成本估计重写渲染器；先测量再确定修改范围。

- [K73] **引擎性能修订遵循 vendor 流程**
  - 要点
    - 引擎内部优化写为补丁，重新打包并同步构建说明及哈希测试。
    - 改动前后按同轮测试对照热点，不能直接改 bundle。

- [K74] **自绘测量按内容缓存**
  - 要点
    - 自绘内容尺寸按内容寻址，重复打开可复用测量。
    - 字体代际也是缓存正确性的组成部分，见 K114。

- [K75] **首帧预测量复用元素**
  - 要点
    - 预测量与正式构建复用既有结果，避免同内容重复构建。
    - 分段计时明确包含哪些工作，避免把复用或等待时间重复归因。

- [K76] **大图分片渲染**
  - 要点
    - 使用引擎已有异步通道分散长任务，收尾必须等待真实渲染完成。
    - 分片的总耗时与输入阻塞分别测量，避免只优化其中一项。

- [K77] **历史负结论：内容构建并非主要瓶颈**
  - 要点
    - 性能方案先对热点取证，再决定是否增加新的缓存或重构。
    - 当时的成本分解不能作为其它图规模、宿主或版本的固定比例。

- [K78] **拖宽监听按需注册**
  - 要点
    - 无需拖宽能力的节点不预先注册整套监听；节点销毁释放已注册资源。
    - 监听生命周期由补丁契约与回归验证，不能仅以节点不可见推断监听已释放。

- [K79] **布局平移避免重复遍历**
  - 要点
    - 子树平移的内部优化须保留最终布局几何和一次物化的语义。
    - 算法补丁遵循 vendor 流程，以布局回归与实际复杂度测量验证。

- [K80] **历史负结论：镜像序列化**
  - 要点
    - 未超过测量噪声的优化不保留额外复杂性。
    - 已回滚候选只作证据，不能作为现行架构要求。

- [K94] **历史性能复核仅作基线**
  - 要点
    - 解析、渲染与长会话读数用于后续同条件对照。
    - 不把历史测试数量或毫秒数写成当前固定验收值。

- [K81] **社区 scanner 作为护栏**
  - 要点
    - 本地门禁与社区校验面持续对照，防止后续配置收窄。
    - 当时无实质缺口的审计结论不是所有后续版本的免检证明。

- [K82] **构建对照官方模板**
  - 要点
    - 模板对照用于确认构建、工作流与开发要求，没有依据不替换现有技术选择。
    - 当前配置以真实文件为准，模板或工作流升级后重新核对差异。

- [K83] **lint 规则先核对实际拦截力**
  - 要点
    - 新规则先做正负探针，避免把误报当合规缺口。
    - 未验证实际拦截力的规则不接入门禁；误报与缺口分别处理。

- [K84] **许可声明随副本分发**
  - 要点
    - 发布三件套同时附带项目许可证与第三方许可说明。
    - 内联 bundle 注释不能代替完整许可声明。

- [K85] **数学渲染核对宿主实际能力**
  - 要点
    - 使用宿主实际提供的 MathJax 渲染面，能力缺失要有回退与告警。
    - 官方加载 API 与私有渲染触点分开登记，适配集中在平台层。

- [K86] **数学异步定稿后重测**
  - 要点
    - 离屏同步测量可能先量到占位文本，产物定稿后须重新测量节点。
    - 不能只替换 DOM 而保留旧外框几何。

- [K87] **数学样式就绪后缓存**
  - 要点
    - MathJax 产物缓存和尺寸同步以字体、字符样式确已生效为前提。
    - 容器宽高非零不足以证明公式没有塌缩。

- [K88] **数学重测定位真实节点**
  - 要点
    - 异步定稿不能把预测量代理误当可重渲染的引擎节点。
    - 必须从当前引擎定位真实节点；进一步回退见 K100、K104。

- [K89] **块级数学按闭合定界符切分**
  - 要点
    - 块级数学允许跨行并含单个美元符号，寻找最近的合法闭合。
    - 定界符解释集中在扫描器，不由 UI 再解析。

- [K90] **数学就绪判据尊重零宽字符**
  - 要点
    - 设计上零宽的数学字符不算样式未就绪；块级定界符的合法空白不误挡。
    - 边界与负向样本由数学及 token 扫描回归覆盖。

- [K91] **代码块呈现与复制**
  - 要点
    - 围栏内容保留换行和缩进，复制操作去除围栏及信息行。
    - 最初的无高亮方案已被 K116 更新；按钮呈现见 K115。

- [K92] **节点原文内联编辑**
  - 要点
    - 富节点在节点位置编辑即将回写的原文，提交与取消沿用既有会话机制。
    - 自适应尺寸和统一高亮见 K203、K204；组件分工见 K208。

- [K93] **新节点为空并立即编辑**
  - 要点
    - 新建子节点、同级节点和加号入口使用空文本并进入编辑。
    - 空列表项保留结构；空白双击新建入口已由 K200 移除。

- [K95] **自绘链接以文本呈现**
  - 要点
    - 自绘节点中的链接使用宿主链接色，URL 显示地址文本并可交互。
    - 引擎单槽图标通道与自绘链接通道分开，见 K118。

- [K96] **图片异步校正不丢首帧**
  - 要点
    - 图片匹配兼顾对象身份与节点 uid；root 未就绪时保留待回灌结果。
    - 首帧落地后再消费校正，不能提前清空队列。

- [K97] **图片无参数显示原始尺寸**
  - 要点
    - 显式宽高按参数显示，仅宽保持比例；无参数从自然尺寸取值，超过显示上限时等比缩小。
    - 探测失败先使用安全默认尺寸，自动尺寸不回写，见 K8。

- [K98] **历史规则：新节点标题层级**
  - 要点
    - 新节点语法现在跟随文件实测起点、兄弟位置与父级约束。
    - 早期前六级恒写标题的方案已被 K168、K172、K201 更新。

- [K99] **导出注入宿主主题变量**
  - 要点
    - 导出 SVG 为自绘内容补齐其依赖的宿主 CSS 变量。
    - 屏幕上已有主题变量不代表独立导出环境也有。

- [K100] **数学重测具有定位回退**
  - 要点
    - 缓存复用或预测量使对象关联失效时，按产物元素反查当前节点。
    - 不让可选调用静默跳过真正的尺寸更新。

- [K101] **自绘外链协议白名单**
  - 要点
    - 渲染 href 只接受已有协议白名单，非法地址保留显示回退。
    - URL 判断共用 domain/url，不在 DOM 构建器重写规则。

- [K102] **已废止：同文件多视图互斥**
  - 要点
    - 不阻止多个视图打开同一文档，也不采用后关闭者胜的策略。
    - 当前一文件一会话，见 K180、K194。

- [K103] **已废止：旧保存加固方案**
  - 要点
    - 连续失败挂起与旧保存开关等机制不恢复。
    - 当前两秒防抖、关闭 flush 与外部冲突由共享会话处理，见 K166、K182、K183。

- [K104] **数学产物反查覆盖插件容器**
  - 要点
    - 首帧重测选择器必须识别插件自己的数学 holder。
    - 真实产物、定位成功与几何更新分别验证，不能只检查定稿回调触发。

- [K105] **导出 CSS 值校验保留合法字体**
  - 要点
    - 主题变量校验阻挡结构性注入字符，同时接受合法非 ASCII 字体名。
    - 不用过窄字符白名单使中文或用户字体静默回退。

- [K106] **导出几何留出光栅化余量**
  - 要点
    - 导出 foreignObject 为像素取整留下安全边距，避免临界内容被裁。
    - 余量只作用于导出，不改变交互节点布局。

- [K107] **导出数学容器使用定稿高度**
  - 要点
    - 独立导出环境中保留屏幕已确定的数学高度，避免末行压边或裁切。
    - 字体完整性另见 K130。

- [K108] **插件编辑提交后编排**
  - 要点
    - 原文编辑提交后也要执行主题重命名、候选拆分等已有业务后处理。
    - 不能只依赖引擎编辑事件；输入预览阶段不提交、不保存。

- [K109] **发布检查覆盖说明与许可证**
  - 要点
    - 发布门禁校验必需元数据、许可证与版本说明；scanner 调用采用实际可运行方式。
    - 工具版本变化后验证实际命令可运行，不沿用旧版本的通过结论。

- [K110] **历史性能轮的取舍**
  - 要点
    - 优化以实际画像为依据，几何计算不强制全量 DOM，低收益方向不增加结构。
    - 旧拖拽辅助相关候选已随 K23 废止；数字只作当时证据。

- [K111] **鼠标侧键保留导航历史**
  - 要点
    - 视图让宿主导航事件链正常冒泡，并正确声明导航能力与历史状态。
    - 快捷键失效须查事件链与视图契约，不能再绑定一套后退实现。

- [K112] **工具栏图标尺寸自包含**
  - 要点
    - 工具栏同时设置宿主图标变量和自身尺寸，减少对内部类名的隐式依赖。
    - 当时的旧拖拽辅助内容已废止；局部样式现归组件，见 K207。

- [K113] **MathJax 代际能力适配**
  - 要点
    - 数学就绪检查兼顾宿主实际产物形态，升级后重新核对零宽字符和字体能力。
    - 旧宿主实测是适配依据，不硬编码为唯一运行版本。

- [K114] **字体代际进入测量缓存键**
  - 要点
    - 字体渐进加载后失效旧宽度，避免公式定稿但节点仍使用偏小缓存。
    - 内容缓存与尺寸缓存的代际须一致。

- [K115] **代码复制按钮按需显形**
  - 要点
    - 复制按钮在悬停或键盘交互时可发现，不在常态覆盖代码首行。
    - 定位使用逻辑属性以适应布局方向。

- [K116] **代码高亮使用宿主 Prism**
  - 要点
    - 围栏语法高亮经官方加载入口，呈现和复制沿用宿主行为。
    - 无高亮的早期轻渲染方案仅保留为历史。

- [K117] **减少重复入口与默认副作用**
  - 要点
    - 混排链接自动拆分默认关闭；新建入口、设置和判据优先合并重复能力。
    - 显式批量操作仍保留；已删除命令 ID 不复用。

- [K118] **引擎与自绘链接通道分开**
  - 要点
    - 自绘接管时引擎部分图标通道不可达；功能与测试须验证用户实际走到的通道。
    - 不能用仅存在的数据字段证明图标或点击已工作。

- [K119] **无显示名 token 也保留位置**
  - 要点
    - 图片等 token 用原文锚点参与编辑合成，避免改字时搬到行尾。
    - 锚点无法匹配时走已定义回退，不猜测破坏新语法。

- [K120] **轻标记支持合法嵌套**
  - 要点
    - 粗体、斜体扫描按定界符语义处理，不用排除所有星号的简化规则。
    - 相邻标记与嵌套标记共同回归，补充修复见 K126。

- [K121] **文件属性声明导图**
  - 要点
    - 文件名后缀不再作为自动接管判据，启用与布局遵守当前属性契约。
    - 不自动迁移旧声明，见 K14、K213。

- [K122] **Markdown 围栏只读嵌入**
  - 要点
    - mindmap 代码块提供只读导图；布局指令和全局默认由组合根注入。
    - 不挂编辑、保存或完整视图依赖；主题和连线默认与按文件偏好分开。

- [K123] **GFM 表格在节点内渲染**
  - 要点
    - 表格按块识别，使用内联样式与宿主主题变量呈现。
    - 保护区内不识别表格；表格行后写指令不能制造额外单元格。

- [K124] **切回 Markdown 保留原模式**
  - 要点
    - 视图状态正确记录和恢复编辑或阅读模式。
    - 返回 Markdown 不能一律落到编辑态。

- [K125] **历史宿主约定：Windows 终端**
  - 要点
    - 当时的 Windows 调用形式与 WSL 别名问题保留为历史依据。
    - 当前会话按实际 macOS/zsh 工具执行，不能照搬 Windows 路径。

- [K126] **渲染保真与跨窗口能力判定**
  - 要点
    - 相邻和嵌套标记分别识别；图片手柄等通过能力判定支持 popout。
    - 新引用遵循宿主路径偏好，存量原文不被新引用逻辑扩写。

- [K127] **边框与明暗主题正交**
  - 要点
    - 边框预设只表达填充与宽度，不改字号、间距、连线或主题描边色。
    - 无边框仍保留真实描边色供缩略图取墨；偏好作用域以 decisions.md 为准。

- [K128] **整篇配色按文件记忆**
  - 要点
    - 配色与明暗、边框分别管理；预设及自定义颜色经统一解析。
    - 当前短 id 不接旧名称别名，见 K213；只读嵌入使用既定默认配色。

- [K129] **右缘竖栏与右键菜单分工**
  - 要点
    - 竖栏保留文档、外观开关、视图与历史四组；布局和配色采用右键级联。
    - 常驻整理按钮已移除，见 K206；组件装配边界见 K207。

- [K197] **脚注只读交互**
  - 要点
    - 引用显示轻量徽标并按当前文档原文找定义，定义行仍保留节点。
    - 徽标不缓存定义正文；交互期索引从当前渲染树取数据，不制造另一份快照。

- [K198] **会话快照补图片显示尺寸**
  - 要点
    - 解析树进入引擎前补齐缺失尺寸，并复用本视图已探测的同地址尺寸。
    - 尺寸是显示派生，不回灌权威树或修改正文。

- [K207] **工具栏与搜索组件内聚**
  - 要点
    - ui 组件内聚骨架、局部交互与样式，features 适配业务状态和回调。
    - 组件不持有视图、引擎、Vault 或保存服务；样式从统一 CSS 入口构建。

- [K208] **编辑会话与编辑组件分工**
  - 要点
    - features 管理会话、原节点暂藏及提交守卫；ui 管理文本框、输入、焦点和测量。
    - 样式旁置并保留既有坐标、缩放与尺寸契约，不改变输入与提交时序。

- [K209] **内容 UI 与解析模型分离**
  - 要点
    - features 保留自绘接管和唯一段分派；ui 管理各段 DOM 与样式；共享段模型在 core。
    - 图标、公式、mermaid 与预览以窄接口注入，UI 不访问引擎或 Vault，不重新解析。

- [K210] **能力子目录不增加依赖层**
  - 要点
    - platform 与 features 按能力分目录，一级组仍是依赖许可单位。
    - 迁移同步真实 import 与完整路径索引，不添加无必要转发入口。

- [K211] **测试目录对齐主要职责**
  - 要点
    - 模块测试跟随源码能力目录，工程契约集中于 contracts，公共测试资源单独保留。
    - 不强求一源一测；组合入口测试留根目录，迁移不改断言。

- [K212] **配置与执行脚本归档**
  - 要点
    - 显式加载配置归 config，执行脚本归 scripts；自动发现的约定入口留根目录。
    - 路径相对真实配置位置计算，工作目录和工具扫描范围须有回归。

- [K213] **只实现当前数据契约**
  - 要点
    - 允许破坏性演进，删除旧属性迁移、旧布局与配色别名等历史读取兼容。
    - 非法值走当前默认或拒绝路径；启动不迁移写盘，宿主 API 适配与 Markdown 保真继续保持。

- [K214] **版本标签指向需求完成快照**
  - 要点
    - v0.x.x 标签标对应需求最终完成点；base 取上一完成点，版本号提交另外记录。
    - 映射依版本说明与真实差异确定，一版可跨多次实现；不与发布流程中的版本标签混用。
